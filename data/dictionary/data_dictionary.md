# 第一周数据字典草案

本文件记录第一周数据生成所需字段、枚举值和待确认事项。正式接口字段以接口文档为准。

## 通用枚举

- `network_type`：`HF` 表示短波，`VHF` 表示超短波。
- `node_type`：`fixed` 固定站，`mobile` 移动站，`relay` 中继站，其他取值待确认。
- `status`：`normal` 正常，`degraded` 性能下降，`fault` 故障，`offline` 离线，其他取值待确认。
- `source`：`raw` 公开原始资料，`synthetic` 自行构造，`manual_or_synthetic` 人工整理或构造。

## 待确认事项

- 设备状态上报协议及接口文档待确认。
- Python 与 Java 的接口字段规范待确认。
- DEM 地形数据来源、授权状态和覆盖范围待确认。
- 设备型号、设备说明书来源和可公开使用范围待确认。
- 故障知识图谱训练语料来源与规模待确认。
- ML 层故障诊断是否纳入本次验收范围待确认。
