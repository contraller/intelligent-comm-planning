# 文档导航

系统的当前入口和目录结构见根目录[README](../README.md)，维护约定见[PROJECT_RULES](../PROJECT_RULES.md)。

| 内容 | 位置与用途 |
| --- | --- |
| 需求输入 | [input](input/README.md)，保存原始输入资料；当前需规对照为根目录`无线需规v3(3).docx` |
| 数据字段 | [数据字典](design/01_数据字典.md) |
| 接口契约 | [接口文档](design/03_接口文档.md)、[页面接口矩阵](design/13_新版前端接口对照矩阵.md) |
| 模块与算法 | [模块关系](design/04_模块接口关系说明.md)、[算法设计总览](design/05_算法设计总览.md) |
| 架构决策 | [ADR](adr/0001-task-input-versioned-snapshots.md) |
| 需求编写来源 | `draft/`和`output/SRS-selected-sections.md`，保留需求条目与来源追踪 |
| 验证依据 | `review/`，按日期和对应程序版本判读，专项结果不代表全部验收 |

正式用户手册、软件研制总结及验收文档在本地`docs/output/`维护，完整交付另附Word、PDF和校验清单。运行数据库、账号、私密配置和内部接手材料分别受控保管。

已被现行源码和文档取代的旧交接副本、过期分工任务单及重复版本不再作为当前维护入口；既有版本历史保留。
