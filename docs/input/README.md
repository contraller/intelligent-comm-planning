## 使用规则

- 编写需求章节时，优先读取本目录中的原始资料。
- 不得直接改写原始资料内容；如需摘录、转写或追踪，应在草稿或输出稿中完成。
- 对资料中不明确、相互冲突或超出当前验收口径的内容，应按 `AGENTS.md` 标注“待确认”或作为扩展设计目标处理。
