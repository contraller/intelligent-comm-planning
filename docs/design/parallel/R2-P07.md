## 4. 来源接口与精确数据对象

新接口统一 code/message/data 包络；成功 code=0。全部来源为 SYNTHETIC_INTEGRATION。本文数目/大小上限是隔离实现保护，不增加项目验收指标。

标识沿用首批 Identifier：ASCII `[A-Za-z0-9_.:-]`，1–120字符。页码 page 为1起安全整数，page_size为1–100、默认20；拒绝重复查询键/未知字段/布尔冒充数字/NaN/Infinity。时间为带时区 RFC3339，保存事件时间不冒充 observedAt。

| 对象 | 精确字段 |
|---|---|
| SourceDraft | name:string(1–60,无首尾空白)；protocolHint:null或HTTP_JSON或WEBSOCKET_JSON；endpoint:null或string(1–500)；intervalSeconds:null或整数1–3600；minKhz/maxKhz:同时null或有限数且0<min<max；enabled:boolean；provenanceNote:string(1–500) |
| SourceVersion | schemaVersion:1、dataOrigin、sourceId、configRevision、contentHash、draft:SourceDraft、createdAt、actorId |
| SourceRow | SourceVersion全部字段，加 latestOfflineCheck:OfflineCheck或null；只选同configRevision的最近检查 |
| FieldIssue | field:string、code:MISSING或INVALID、message:string |
| OfflineCheck | checkId、sourceId、configRevision、checkedAt、validation:VALID或INCOMPLETE、connection:NOT_ATTEMPTED、validationMode:OFFLINE_ONLY、issues:FieldIssue[] |
| SourceReceipt | requestId、operationType:SOURCE_SAVE或SOURCE_CHECK、sourceId、configRevision、changed:boolean、actorId、committedAt、source:SourceVersion或null、check:OfflineCheck或null |
| OperationLookup | schemaVersion:1、dataOrigin、requestId、operationType、status:COMMITTED或NOT_FOUND、receipt:SourceReceipt或ObservationImportReceipt或null；具体路由只接受本类型回执 |

protocolHint/endpoint 是输入声明，非真实采集协议确认。离线校验只解析结构：地址不含账号/密码/空白/反斜杠/片段；声明格式与URI scheme匹配；缺失元数据保留INCOMPLETE。没有DNS、HTTP、WebSocket、端口探测或后台采集。VALID仅表示离线结构有效，不使数据就绪、不生成帧。

新工厂 `createSpectrumSourceHttp(request: AuthenticatedRequest): SpectrumSourceServices`，方法与 wire 对应如下；RequestOptions含signal，全部调用捕获发起参数副本，写入draft单独复制。

| 方法/路径 | 请求 | data/文件响应 |
|---|---|---|
| GET /api/v1/spectrum/sources | page、page_size、可选search(0–120)、enabled=true或false | {schemaVersion,dataOrigin,items:SourceRow[],page,pageSize,total}；按sourceId升序 |
| GET /api/v1/spectrum/sources/{source_id} | 可选config_revision；UI点行时必须传所选版本 | SourceVersion；不传时明确读取该源当前配置，不改指针 |
| POST /api/v1/spectrum/sources | {schemaVersion:1,requestId,sourceId,baseConfigRevision:null或string,draft:SourceDraft} | SourceReceipt；新增base=null，修改/启停须CAS匹配原版本 |
| POST /api/v1/spectrum/sources/{source_id}/checks | {schemaVersion:1,requestId,configRevision} | SourceReceipt(check非null)；记录实际离线检查事件，拒绝demo/模拟成功参数 |

## 5. 显式观测导入、核实与导出

四个现有GET及各自参数/响应继续复用：context、datasets分页、datasets/{id}/frames分页、datasets/{id}/frames/{index}。保留schemaVersion=1、SYNTHETIC_INTEGRATION、null/unknownReasons、datasetRevision和source声明；不套用CURRENT或旧非空监控模型。

ObservationImportFile精确为 {schemaVersion:1,fileKind:SPECTRUM_OBSERVATION_DATASET,dataOrigin:SYNTHETIC_INTEGRATION,dataset:{datasetId,provenanceNote,resourceRevision,deviceStatusSnapshotId:null,source:ObservationSource,frames:ImportedFrame[]}}。source/frame/bin字段、1–256帧/每帧1–256bin与未知原因约束沿用首批；不新增实测类型。公共JSON限制2MiB；超过限制返回413/1001而非截断。既有内部大对象不自动改写，导出超过同一保护限制也明确拒绝。

| 方法/路径 | 请求 | data/文件响应 |
|---|---|---|
| POST /api/v1/observations/spectrum/import-preview | {file:ObservationImportFile} | {schemaVersion,dataOrigin,previewHash,datasetId,resourceRevision,source:ObservationSource,frameCount,sourceBinding:REGISTERED_VERSION或DECLARED_ONLY,warnings:string[]}；全量结构/来源预检，零写入 |
| POST /api/v1/observations/spectrum/imports | {requestId,previewHash,file:ObservationImportFile} | OperationLookup(status=COMMITTED,receipt为既有ObservationImportReceipt)；服务端重算规范摘要，不信任前端预检 |
| GET /api/v1/observations/spectrum/imports/{request_id} | 无业务参数 | OperationLookup，operationType=OBSERVATION_IMPORT；未知键为NOT_FOUND，不假报提交失败或取消 |
| GET /api/v1/observations/spectrum/datasets/{dataset_id}/export | 必填dataset_revision | application/json附件，ObservationImportFile；从指定不可变集读取原帧，不按当前资源或配置重算 |

previewHash为归一化旧ObservationImportRequest内容（排除requestId）的完整SHA-256，与原dataset内容哈希口径一致；文件包装字段不混入旧数据集哈希。提交解包后复用原显式导入事务和现有operation表，不再建一份观测库或回执库。HTTP补actor归属校验，actor只来自服务器会话。

来源身份语义：resourceRevision保证读取核验时的历史资源身份，不保证提交时仍为当前资源，不声称资源校验与观测写入同事务。sourceId/configRevision来自显式导入声明；只有精确匹配已登记不可变来源版本及可比字段时展示REGISTERED_VERSION。老数据或未登记来源为DECLARED_ONLY，显示原因；GET不自动建来源/改原始标签。登记来源也不代表真实协议/连通已验证。配置更新/停用不覆盖已导入帧，历史始终按原身份回读。

为完成现有数据条件下的非空流程，可提供“导入既有构造样本”：只在用户明确选择/预检/确认后，将已有 spectrum-observation-presets.ts 的值送入同一HTTP入口。保持原observedAt、occupancy、power、异常/原因数值不变，仅做契约字段名映射和明确的来源元数据绑定，provenanceNote记录原预设标识。不能在GET、页面启动或播放时取预设冒充库数据；不新写随机样本、不从规划频点推导观测、不自动补未知实测值。

新ObservationServices仅增 previewObservationImport({file,signal})、importObservationDataset({requestId,previewHash,file,signal})、getObservationImportReceipt({requestId,signal})、exportObservationDataset({datasetId,datasetRevision,signal})；保留原四读方法及工厂AuthenticatedRequest注入。本组不改http.ts或types.ts来强转旧PreviewService。

| 403/1104 | 缺权限、跨actor读取私有回执 |
| 403/1105、409/1106 | CSRF拒绝/会话替换，沿用统一身份检查，不在本组改变语义 |
| 409/1204 | 来源CAS基线、指定观测版本或回执操作类型不匹配 |
| 409/1205 | 导入来源读取时资源版本变化；历史读取不要求当前资源一致 |
| 409/1206 | requestId异内容/异actor、datasetId异内容；previewHash与提交内容不符 |
| 503/5001、5002、5003 | 配置/存储不可用、坏哈希/缺表、资源基线未初始化；不回退Mock或自行建表 |

来源SAVE/CHECK分别计算包含operationType、规范输入及sourceId的摘要；requestId在本来源操作表唯一。同键同摘要同actor重放原回执，不重复换版/检查；异内容/actor/类型冲突。新增/修改/启停在同一事务写不可变版本、CAS当前指针和操作回执，CAS失败整批回滚。同内容新requestId在基线仍匹配时返回changed=false并保存实际回执，不升版本。

观测导入复用首批幂等与原子事务；原请求重放先核实既有回执，不被后续当前资源换版误拒绝。预检不写库；写请求取消或超时只表示客户端不再等待，不能宣称服务器已回滚。UI保留同requestId/file/hash，先GET核实，再按用户明确操作以相同内容重试，禁止自动换ID重复导入。GET全路径只读，空数据只返回空，不初始化资源、来源或帧。
