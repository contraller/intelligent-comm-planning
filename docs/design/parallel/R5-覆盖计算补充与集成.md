## 契约原则

1. 不扩带宽选择请求：缺失参数在新资源版本中显式补充，新任务正常规划并冻结新资源，沿现有选择保存/计算流程。原资源、旧选择、旧方案及旧缓存保留其原语义。
2. 新引擎版本明确区分无活动频率的SKIPPED和活动设备资料不足的UNAVAILABLE；只对实际计算对象评定完成，零对象不得伪报COMPLETE。汇总必须与逐设备状态一致。
3. 构造带宽的来源、版本、资料摘要和非厂家声明在冻结型号/选项/结果及页面可见，不能因为填写了数值就冒充原始手册值。
4. 既有异步、取消、缓存、射线/格点和输出限额不放宽；跳过设备不做传播计算。同设备同频率仍只算一次，实际耗时由同参数实跑比较，不预填通过。
