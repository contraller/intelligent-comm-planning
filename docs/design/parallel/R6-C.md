### 2.1 入口、选择器和结果登记

- `BASE` 由主会话核实正在运行的同源新版入口及源码/包、API、数据库归属后填写。本组没有探活。文件13开头 `.19:5319` 和文件16早期入口已被后续记录覆盖，不能直接当在线地址；R5历史是 `.23:5323/8123`，R4历史是 `.22:5322/8122`，均不是本文件对当前在线状态的承诺。不得对原5183或其他组的库执行准备性写入。
- 六个工作路由为 `#/situation`、`#/resources`、`#/planning`、`#/diagnosis`、`#/knowledge`、`#/system`；另有 `#/login`。没有独立干扰、频点、设备或频谱路由。真实 HTTP 模式应显示“账号登录”，不以 Mock 演示或演示分支取代。
- 选择器记法：文本按钮 `B(文案)` = `getByRole('button').filter({hasText: /^\s*显示文本\s*$/})`；实现时转义文案中的正则字符并容忍文案内部空白。PrimeIcons的CSS伪元素字符会进入accessibleName，不能用纯文本exact名称匹配带图标的文本按钮。显式aria-label图标按钮仍按可访问名称精确匹配。`L(标签)` = `getByLabel(标签, {exact: true})`；`Q(css)` = `locator(css)`；`ROW(id)` = 当前表格内按完整编号定位的行。动态计数按钮用已显示的完整文案或锚定正则，如 `^对比所选 2 个版本$`、`^勾选该型号（\d+）$`。这只是供主会话选择控件的记法，本组未执行脚本。
- 抽屉先按标题限定可见范围，再找内部控件；新版使用 `AppDrawer`/PrimeVue Drawer。可从可见 `.p-drawer` 按标题过滤，并确认只有一个命中。确认框按可访问 dialog 标题限定。重复的“导入/导出/关闭/查询/上一页”必须限定所属页签、抽屉或记录行；不使用全页 `.first()`、强制点击或隐藏控件冒充用户操作。图标控件优先按下面列出的 `aria-label`。
- `details/summary` 必须先点开；原生 select 按真实 option 的编号/value选择，不能假设动态选项的名称。地图 canvas 内的节点不能用虚构 DOM 选择器；先从树、列表、链路/通联 select 定位同一对象，再核对地图高亮。
- 每条记录 `编号、身份、URL、资源/任务/方案/快照/请求号、实际按钮、操作前后状态、截图、浏览器网络事件/错误、下载文件名与大小、结论`。写成功必须从页面刷新或历史重开回读；下载必须有浏览器下载事件且文件可读取，不以点击无报错判通过。口令、Cookie、CSRF和密钥不得进入截图/文档或另存明文。
- 结果只用：`浏览器通过`、`浏览器失败`、`阻断（原因/依赖）`、`无控件`、`外部不纳本轮`、`未执行`。保留首次失败；选择器错配、未展开或终态到达后取消按钮消失，先核对状态，不直接判生产失败。HTTP回读可作佐证；单独 curl/TestClient、组件宿主、Mock、请求桩或直接引擎结论均不能填“浏览器通过”。
