## 2. 范围与排除项

软件只接收调用者显式提供、明确标记 `SYNTHETIC_INTEGRATION` 的完整频谱观测集。导入为内部服务函数，不开放 HTTP 写路由，不新增导入脚本、定时任务、采集连接或网络地址配置。所有帧来自该次输入，不通过规划频点、算法预测、设备配置或当前时间生成观测值。

本批提供四个只读 HTTP 接口，以及独立前端适配器。回放使用同一不可变观测集的有限索引，末帧停止，不循环、不延长数据集、不推进服务端游标。上下文为空时直接返回空状态，不初始化资源或观测表，不创建默认来源或默认帧。

本批不复制 P06 的设备状态、在线判定、告警或配置回执逻辑。`deviceStatusSnapshotId` 暂只接受和返回 `null`；非空引用须待 P06 契约先行并另批审核。观测集不宣称已建立与设备状态的同步快照。

真实设备协议、采样周期、地址、实测数据来源及生产身份源均为待确认。本批的数量上限是隔离实现的输入保护，不是新增验收指标。

## 4. 数据对象与版本

内部导入与 HTTP 的业务字段统一采用下列 camelCase；HTTP 查询参数使用第 6 节列出的 snake_case。未列出的输入字段、重复查询键、重复对象 ID、NaN、Infinity、布尔值冒充数字、无法解析的时间均拒绝，不静默丢弃。

| 对象 | 精确字段与约束 |
|---|---|
| 通用标识 | `datasetId`、`sourceId`、`configRevision`、`resourceRevision`、`frameId`、`requestId`：非空 ASCII 字符串，1–120 字符，仅 `[A-Za-z0-9_.:-]`；`binId` 同规则 |
| `SourceSnapshot` | `sourceId`、`name`（去首尾空白后 1–60 字符）、`configRevision`、`minKhz`、`maxKhz`（有限数，`0 < minKhz < maxKhz`）、`intervalSeconds`（`null` 或 1–3600 的整数）。这些都是输入声明的展示元数据，不代表采集配置已验证；不含 endpoint、protocol、enabled、连通性或检查回执 |
| `SpectrumBin` | `binId`、`minKhz`、`maxKhz`、`occupancyPercent`（`null` 或 0–100 有限数）、`powerDbm`（`null` 或有限数）、`abnormal`（布尔或 `null`）、`reason`（`null` 或 1–500 字符）、`unknownReasons`（无重复字符串列表，每项 1–200 字符，最多 16 项） |
| `ImportedFrame` | `frameId`、`index`（从 0 起连续整数）、`observedAt`（`null` 或含时区的 RFC3339 时间）、`label`（1–120 字符）、`bins`、`occupancyPercent`（`null` 或 0–100 有限数）、`abnormalBandCount`（`null` 或 0 至本帧 bins 数量的整数）、`unknownReasons`（同上） |
| `DatasetSummary` | `datasetId`、`datasetRevision`、`schemaVersion: 1`、`dataOrigin: "SYNTHETIC_INTEGRATION"`、`provenanceNote`、`resourceRevision`、`deviceStatusSnapshotId: null`、`source: SourceSnapshot`、`frameCount`、`firstObservedAt`、`lastObservedAt`、`importedAt`、`contentHash` |
| `StoredFrame` | `ImportedFrame` 的全部字段，加 `datasetId`、`datasetRevision`、`dataOrigin: "SYNTHETIC_INTEGRATION"` |

每集 1–256 帧，每帧 1–256 个 bin。bin 在本帧内 ID 唯一，按 `minKhz` 升序且不重叠，范围完全落在 `SourceSnapshot` 频段内。帧 ID 在同集内唯一；不同帧可复用 bin ID 表示同一频段。已知 `observedAt` 按索引非递减；未知时间保持 `null`。

任何可空观测字段为 `null` 时，所属对象的 `unknownReasons` 必须非空；不能用零、正常、在线或当前时间替换未知。`abnormal=true` 必须有 `reason`；异常判定和占用率均按输入保存，不从功率或规划频率计算。全部 bin 的异常标记已知时，`abnormalBandCount` 必须与其计数一致；存在未知异常标记时，汇总计数为 `null`。总体占用率仅保留输入声明，不补算平均值。

`firstObservedAt`、`lastObservedAt` 分别取首末索引帧的 `observedAt`，允许为 `null`，不跳过未知帧。`importedAt` 为实际导入事件的 UTC 时间，不冒充观测时间。`provenanceNote` 为必填 1–500 字符，必须说明构造来源；首批拒绝 `MEASURED`、`IMPORTED_MEASUREMENT`、`UNKNOWN` 或缺失来源标签。

`contentHash` 为已验证数据集内容的完整 SHA-256：使用规范 JSON（键排序、固定紧凑分隔符、UTF-8、保留 null、拒绝非有限数），已知时间统一 UTC 六位小数 `Z` 形式；覆盖 schemaVersion、datasetId、dataOrigin、provenanceNote、resourceRevision、deviceStatusSnapshotId、source 和完整有序 frames。排除 requestId、actorId、importedAt 及服务端回执。`datasetRevision = "observation-" + contentHash`，不使用当前资源指针或导入时间换版。

`resourceRevision` 在首次导入的来源读取校验时必须匹配本隔离库当前资源版本；使用既有 `resource_dataset_service.current(factory=...)` 的独立只读 Session 校验，不初始化、不改资源。本批保证该读取时点的不可变资源身份，**不保证观测提交时该版本仍是当前资源，也不声称资源来源与观测写入在同一事务绑定**。来源读取之后发生资源换版时，观测可按已核验版本作为历史来源导入成功，回执仍返回原 resourceRevision，不能把它解释为提交时的 CURRENT。之后读取固定已导入版本，即使当前资源已换版也不拼接新资源。若后续要求提交时仍当前，须另行审核同事务/并发门禁，不能靠本批回执推断。

`source_snapshot` 的 sourceId/configRevision/name/频段/intervalSeconds 仅来自本次显式构造导入的来源声明；没有读取采集配置主表，没有校验真实地址、协议、采集检查或配置启用状态。configRevision 是声明身份，不能当成已验证的真实采集配置版本。观测集/帧的 SYNTHETIC_INTEGRATION 与 provenanceNote 随回读保留。

## 5. 唯一写入口：服务层显式导入

拟提供函数签名：

```python
def import_synthetic_dataset(
    request: ObservationImportRequest,
    *,
    actor_id: str,
    factory: sessionmaker[Session],
) -> ObservationImportReceipt:
    ...
```

- 不注册 POST、PUT、PATCH、DELETE，不新增 CLI、脚本或前端导入调用。必须显式传入本组数据库会话工厂；没有默认数据库工厂、来源或 actor。
- `ObservationImportRequest` 精确字段：`schemaVersion: 1`、`requestId`、`datasetId`、`dataOrigin: "SYNTHETIC_INTEGRATION"`、`provenanceNote`、`resourceRevision`、`deviceStatusSnapshotId: null`、`source: SourceSnapshot`、`frames: ImportedFrame[]`。
- `actor_id` 为非空 1–120 字符，取可信内部调用方的实际身份；不从观测正文读取。隔离测试身份明确标为测试用途，不冒充正式账号。函数只允许显式联调模式和数据库资源模式；不是可从外部未授权调用的写接口。
- 返回 `ObservationImportReceipt`：`requestId`、`actorId`、`datasetId`、`datasetRevision`、`dataOrigin`、`resourceRevision`、`frameCount`、`changed`、`importedAt`；全部来源于实际事务。
- 幂等键为全局唯一 `requestId`。同请求 ID、同完整请求摘要、同 actor 返回原回执，不新增帧；同键异内容或异 actor 拒绝 `1206`。先核对已持久化回执，再对首次导入校验当前资源，以允许资源换版后的原请求重放。
- 同 datasetId、相同内容与原 actor、不同 requestId 可复用原观测集，新增幂等回执，返回 `changed=false`；不同内容或不同 actor 拒绝 `1206`。不提供覆盖、追加帧、删除、重置或当前观测指针。
- 数据集、全部帧、回执在同一事务提交；任一帧非法整批拒绝。唯一约束冲突后回滚并在新事务核实原回执，不能把竞争失败写成成功。
- 成功导入不说明真实设备在线、真实采集成功或频率获准使用。

## 6. 精确 HTTP 契约

路由前缀：`/api/v1/observations/spectrum`。全部接口无请求体、仅 GET，返回 HTTP 200、`{"code":0,"message":"success","data":...}`；错误保留真实 HTTP 状态和 `code/message/data`，`data` 为 `null` 或字段问题列表。

读取权限统一复用 `integration_identity_service.require(request, "situation.view")`。必须显式开启 `FRONTEND_INTEGRATION_DEMO=1`；身份失败不降级为匿名 Mock。`X-Session-Id` 若传入，按现有服务核对；GET 不要求 CSRF，不调用身份切换或创建会话。正式身份接入仍待确认。

| 方法与完整路径 | 精确查询参数 | `data` 精确字段 |
|---|---|---|
| `GET /api/v1/observations/spectrum/context` | 可选 `dataset_id` 与 `dataset_revision`，必须成对传入；除此无业务参数 | `schemaVersion: 1`、`dataOrigin`、`datasetCount`、`selected: DatasetSummary\|null`、`reasons: string[]`、`replay: {mode:"FINITE",loop:false,maxFramesPerDataset:256,maxBinsPerFrame:256}` |
| `GET /api/v1/observations/spectrum/datasets` | `page`：1 起整数，默认 1；`page_size`：1–100 整数，默认 20 | `schemaVersion: 1`、`dataOrigin`、`items: DatasetSummary[]`、`page`、`pageSize`、`total` |
| `GET /api/v1/observations/spectrum/datasets/{dataset_id}/frames` | 必填 `dataset_revision`；`page`、`page_size` 同上 | `schemaVersion: 1`、`dataOrigin`、`datasetId`、`datasetRevision`、`resourceRevision`、`sourceId`、`configRevision`、`frameCount`、`items: StoredFrame[]`、`page`、`pageSize`、`total` |
| `GET /api/v1/observations/spectrum/datasets/{dataset_id}/frames/{index}` | 必填 `dataset_revision`；`index` 为非负十进制整数路径参数 | `schemaVersion: 1`、`dataOrigin`、`datasetId`、`datasetRevision`、`resourceRevision`、`sourceId`、`configRevision`、`index`、`frameCount`、`hasPrevious`、`hasNext`、`frame: StoredFrame` |

`dataOrigin` 全部固定为 `SYNTHETIC_INTEGRATION`，每条摘要、帧仍保留自己的来源字段。`context` 未选择数据集时 selected 为 null：零数据集时 reasons 为 `["NO_IMPORTED_DATA"]`，否则为 `["DATASET_NOT_SELECTED"]`；显式选择有效集时 reasons 为 `[]`。不默认选择最新集。

数据集目录固定按 datasetId 升序；帧固定按 index 升序。超出末页返回空 items 并保留 total；不存在的单帧索引返回 404。不存在数据集优先返回 404，存在但 revision 不匹配返回 409，不返回另一集的帧。`total` 在帧分页中等于 frameCount，hasPrevious 为 `index > 0`，hasNext 为 `index + 1 < frameCount`。

目录是显式刷新时的清单，不新增全局目录指针；既有数据集不变，后续显式导入可增加新项。若要跨页稳定显示，客户端保留已读取目录及选中的 datasetId/datasetRevision，不把新目录内容混进已选帧。单集分页与索引通过不可变 revision 保持一致。

GET 路径中不得调用 `create_all`、导入函数、资源初始化、commit、业务 INSERT/UPDATE/DELETE、后台任务或网络采集。空数据需要表已由集成迁移建立；缺表返回存储不可用，不能隐式建表。除只读事务的关闭/回滚外不产生持久化动作。

### 错误码、幂等与版本边界

以下为本批复用的既有业务码；具体 message 表述可指出字段，但不泄漏数据库连接信息。服务层非法导入由 Pydantic ValidationError 拒绝；因本批无 HTTP 导入路由，不把它登记为已上线的 HTTP 422 写接口。

| HTTP / 业务码 | 适用条件 |
|---|---|
| `422 / 1001` | 非法参数、重复参数、未知字段、来源不符、非空 P06 引用、非法帧或数值、超出本批上限 |
| `404 / 1002` | 数据集不存在，或单帧索引超出已存范围 |
| `401 / 1101` | 显式联调模式未开启；沿用现有身份服务 |
| `403 / 1104` | 缺少 situation.view；沿用现有身份服务 |
| `409 / 1106` | 已失效 Cookie 或请求会话已变化；沿用现有身份服务 |
| `409 / 1204` | 存在的数据集与请求 dataset_revision 不一致 |
| `409 / 1205` | 首次服务层导入的 resourceRevision 不等于来源读取校验时的当前隔离资源版本；不承诺提交时仍当前 |
| `409 / 1206` | 导入 requestId、datasetId 的内容或身份冲突 |
| `503 / 5001` | 数据库配置缺失或本批所需数据库模式未开启 |
| `503 / 5002` | 数据库不可用、观测表未迁移、持久化数据结构/哈希损坏；禁止回退到文件或生成帧 |
| `503 / 5003` | 首次导入时隔离资源基线未初始化；禁止导入函数自行初始化 |

四个 GET 都无幂等键，无进度、副作用或回执。revision 不匹配不能自动刷新后返回新数据；前端必须保留旧结果并显式报告冲突。

## 7. 数据库建议与共享集成请求

`observation_models.py` 使用模块自有 `ObservationBase.metadata`，不修改共享 Base 或全局模型注册。测试只对该 metadata 和必要的既有资源/会话表显式建表，不导入 `app.main`。建议三张新表，迁移名称、编号、DDL 与注册由主会话审定，本组不创建迁移文件：

| 表名 | 列与约束建议 |
|---|---|
| `observation_datasets` | dataset_id 主键；dataset_revision 唯一；schema_version、data_origin、content_hash、metadata_hash、resource_revision、provenance_note、source_snapshot JSON、device_status_snapshot_id 可空、frame_count、first_observed_at 可空、last_observed_at 可空、actor_id、imported_at；CHECK 限定 schema=1、构造来源、frame_count 1–256 和 device_status_snapshot_id IS NULL |
| `observation_frames` | 复合主键 (dataset_id, frame_index)；frame_id、frame_payload JSON、frame_hash；外键 dataset_id 指向 observation_datasets，删除 RESTRICT；UNIQUE(dataset_id, frame_id)；CHECK frame_index 0–255；索引查询沿用复合主键 |
| `observation_import_operations` | request_id 主键；request_digest、actor_id、dataset_id 外键、receipt JSON、created_at；回执与帧同事务提交 |

## 8. 前端适配器精确边界

`createObservationHttp(options)` 返回独立 `ObservationServices`；options 为 `{baseUrl:()=>string,fetcher?:typeof fetch,origin?:()=>string|undefined,timeoutMs?:number}`。只读复用既有 `resolveAuthApiBaseUrl`、`createHttpClient` 和 `ApiError`，不改共享客户端；严格同源、credentials=same-origin、redirect=error、cache=no-store，支持调用者 AbortSignal 和默认 15000 ms 超时。
