## B1 契约无关编辑器

主批准先实现上述新增组件/专项测试/本记录三个路径，其余等待统一DTO。组件内的CoverageBandwidthRow及确认意图只是本地展示模型，不是wire字段或后端枚举；未连接服务、计算、缓存、地图或资源写入。

- 分页固定20项、表格与确认清单独立固定高度，长清单内部滚动，不因翻页/筛选挤占地图；默认不勾选设备、不取第一个带宽，即使只有单一选项也不补“人工已选”。
- 明确未选、合法、无资料及损坏待核验；不能给41台缺带宽或40台无频点编值。来源按宿主提供的服务端回读文本展示。
- 按型号勾选是显式命令；批量下拉仅给所选设备合法交集，先应用到本地待确认清单，预览后人工确认才发确认意图。不自动请求/计算或改旧覆盖。
- 来源切换清理旧意图；失权/读取/写入忙态禁止修改与提交。确认时重新核设备/型号/合法选项/已冻结前值，资料变化不批准旧选择。失败仍保留本地草稿，不宣称已保存。
- 持久化和刷新保留由后续后端版本回读负责，不能靠此组件本地内存或浏览器存储冒充。统一DTO到达后再映射/接线并执行HTTP、状态与地图专项。

## B2 已由主统一的HTTP契约

主批准P04十文件后，本组只读P04 `parallel/R3-P04.md` 第2节及专用实现核对精确DTO，不写P04文件。当前工具未暴露send_input，按主直接消息和该记录接线，后续差异回主而不各定互斥契约。

- GET `/planning-coverages/{plan}/bandwidth-options`（task_id/snapshot_id/context）：`{anchor,devices,current_selection}`。设备含device_id/node_id/model_id/band/model_bandwidth_khz/options_khz/state/reason_code/reason，结构化状态SINGLE_VALUE/SELECTION_REQUIRED/UNKNOWN/NO_ASSIGNED_FREQUENCY。不解析中文reason推断状态。
- POST `/{plan}/bandwidth-selections`：task_id/snapshot_id/request_id/choices（device_id/rx_bandwidth_khz），空choices合法；完整不可变版本，不是单项patch。DTO selection_id/selection_hash/source_anchor/choices/version_no/created_at。GET `/{plan}/bandwidth-selections/{selection_id}` 精确回读；GEToptions恢复同来源最大version_no，不靠浏览器storage。
- source_anchor为冻结anchor去掉engine_version；selection_id为FBS加32位小写hex、selection_hash为SHA256。compute/cache只增加可选bandwidth_selection_id，不把choices塞进URL或八项parameters；V3 job/cache与result.provenance严格回显id/hash，结果另含规范choices和逐设备rx_bandwidth来源。新引擎V01-3，V2历史读取兼容但不能复用为V3选值缓存。
- 前端合并当前已冻结choices与明确人工确认变更，保持未改设备选择；未选不自动填首项。只读GIS不得POST，当前选择跨actor可读，新增仍由服务器owner/execute/CSRF核验；确定错误、未知写入原号、版本冲突与晚响应分别处理。完整接线及测试仍在实施，未提前标为完成。
