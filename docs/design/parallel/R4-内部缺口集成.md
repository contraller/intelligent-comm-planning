## 集成门禁

1. 参数改变必须实际进入筛选/部署，非法或无可行输入给出明确失败，不静默忽略。
2. 必要/非必要集合分别统计；结果明细锚定冻结输入与资源，旧快照缺项继续显示未提供。
3. 推荐只来自所选已发布版本并服从过滤/权限；无关输入不伪造相似知识。
4. 最新源码统一到独立LOCAL身份环境，双worker可核验，地图JSON/PNG/MVT不能回退首页。
5. 定向代码测试、真实HTTP和实际浏览器分别记录；全网实跑保留89/89必要与至少90%抗毁专项，不能用接口桩代替。
