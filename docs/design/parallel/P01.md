日期：2026-10-23。负责人：主会话。基线 43137a3，分支 collab/p1-resource。

## 范围与审核

用户已授权总集成内部审核推进；本批由总集成自审通过并登记在主目录文件 15，不再等待用户逐项确认。只在本树及本树数据库开发和验证，不操作主库或重启 5183。

本批实现新版资源台账现有导出抽屉：CSV 单表、XLSX 多表，全部/全部筛选结果/选中设备范围，按指定当前不可变资源版本读取。筛选或选中时非设备表初始为空；XLSX 同时选节点表时补齐设备所属节点及全部父节点，返回 added 数量，遵循现有页面语义。没有选中节点表时不擅自增加工作表。保留空值、布尔 false 和数值 0；CSV 使用现有 ~rp~+JSON 字符串的公式防护，XLSX 单元格明确文本，不输出公式。

代码核对发现现有设备列表忽略 device_class/status/alert/部署角色/频率及排序；本批将其和导出统一为完整集合先筛选/排序再分页，不在当前页补筛假报总数。搜索沿用设备 ID、型号名、所属节点名；型号频率用区间交集，设备频点用配置值，未知状态不当正常。现有非设备分页、地图空间查询及观测快照不在本批扩展。

## 契约

- POST /api/v1/resource/export/preview：请求 context=ledger、revision、format=csv/xlsx、kinds（nodes/devices/interference_sources）、range=all/filtered/selected；filtered 可带 filter，selected 必须带不重复 selected_ids，最多 50 个。禁止不适用范围字段、GIS/候选链路、操作者、草稿及额外字段。
- preview 响应 data 为 revision、data_origin、source、tables（kind/count，按请求顺序）、added；与前端 ResourceExportPreview 严格映射。每次只固定一份数据库快照，不写版本、指针或回执。
- POST /api/v1/resource/export：相同请求，重新核对当前版本与筛选，返回 Content-Disposition=attachment 的 UTF-8 CSV 或 XLSX；文件内容只来自冻结快照，名称含版本；错误仍是 code/message/data 包络，不能当下载成功。导出最大 20 MiB，超限拒绝而不截断。
- 两个 POST 都使用现有 resources.view 和 require(...,writing=True) 核验会话/CSRF；无新增权限。数据来源 SYNTHETIC_INTEGRATION 明确标注，不声称生产资源。
- GET /api/v1/resource/devices：保留现有 context/revision/page/page_size/search/node_id/availability，补齐 device_class/status/alert/mobility/node_role/relay_capable/frequency_mode/frequency_presence/min_khz/max_khz/sort/order；重复/未知参数、非法组合和观测请求明确拒绝，不静默丢弃。默认仍 ID 升序，缺失排序值放最后，同值按 ID 稳定排序。
- 错误沿用 422/1001 请求无效、404/1002 选中设备不存在、409/1205 资源版本变化、401/1101 未开启联调、403/1104 无权限、403/1105 CSRF 失败、409/1106 会话变化、503/5001 配置缺失、503/5002 数据库或内容损坏、503/5003 未初始化/非数据库导出。预检不是授权令牌，版本变化后必须刷新重新导出。
