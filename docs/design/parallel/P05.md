## 2. 本批交付边界

本批交付供后续身份适配器复用的 DTO、服务端纯策略及前端纯校验。只检查已经由调用方提供的事实，不验证密码、签发令牌、生成会话、创建账户或选择正式身份源。

正式身份采用本地账号还是外部身份源：**待确认**。正式会话存储、登录与退出协议、Cookie 名称、有效期、身份源账户生命周期、角色到权限的正式映射：**待确认**。本批不将现有联调的 Cookie 名称、12 小时有效期或固定角色当作正式约束。

本批不新增 HTTP 路由、数据库表、迁移、环境开关或依赖，不接入页面及主入口。只有本批审核通过后，才创建第 7 节的五个代码文件。

|---|---|---|---|

## 3. 精确 DTO 与上下文契约

本批自有契约版本：`formal-identity-boundary-0.1`，是提议中的内部边界版本，不是真实身份源协议。任何字段或语义变化先升级本记录并重新审核；不静默兼容未知版本。

### 3.1 正式身份 DTO：`FormalIdentity`

| 字段 | 类型与约束 | 来源与含义 |
|---|---|---|
| `contract_version` | 字符串，精确为 `formal-identity-boundary-0.1` | 本批内部 DTO 版本 |
| `session_id` | 非空字符串 | 服务端会话关联标识，不是访问令牌 |
| `account_id` | 非空字符串 | 已验证主体的不透明账户编号 |
| `username` | 非空字符串 | 已验证主体名称，不从请求操作者字段推导 |
| `display_name` | 非空字符串 | 身份适配器提供的显示名称 |
| `role_id`、`role_name` | 两个非空字符串 | 经总集成确认的角色映射；不由角色名称自动补权限 |
| `permissions` | 无重复字符串数组，可为空 | 只能属于调用方提供的权限白名单；未知权限整条拒绝，不过滤后放行 |
| `identity_revision` | 非空字符串 | 身份及权限快照版本，不假设其数值含义 |
| `session_generation` | 非空字符串 | 会话代次，不能由用户名或账户编号代替 |
| `integration_mode` | 布尔值，必须显式为 `false` | 缺失不解释为正式身份 |
| `data_origin` | 字符串，必须精确为 `FORMAL_VERIFIED` | 未来可信适配器验证后的内部来源标记，不是凭据或验真机制 |

所有字符串按 Unicode 标量值计数，长度 1 至 512；拒绝纯空白、首尾空白、U+0000 至 U+001F、U+007F 和孤立代理项，不做隐式 trim、类型转换或标识改写。DTO 只接受上表字段，拒绝额外字段、错误类型、重复权限及未知版本。Python 与 TypeScript 使用一致的字符计数口径。

当前八个基础身份字段沿用 `auth-http.ts` 的名称。本批要求显式出现的 `contract_version/integration_mode/data_origin` 仅约束独立正式 DTO，不直接改变现有联调 DTO 或共享 `AuthIdentity`。版本字段、来源标记均不能让不可信 JSON 变成可信身份。

### 3.2 服务端上下文：`FormalSessionContext`

此对象仅由未来服务端身份适配器构造，禁止从 HTTP 请求体、查询参数、角色头、`accountId` 或前端解码结果反序列化成可信上下文。

| 字段 | 类型与精确取值 |
|---|---|
| `contract_version` | 精确为 `formal-identity-boundary-0.1` |
| `mode` | `ANONYMOUS / FORMAL / INTEGRATION / UNKNOWN` |
| `state` | `ANONYMOUS / ACTIVE / EXPIRED / DISABLED / REVOKED / UNKNOWN` |
| `data_origin` | `FORMAL_VERIFIED / SYNTHETIC_INTEGRATION / UNKNOWN` |
| `source_reference` | 非空字符串或 `null`，是适配器提供的来源引用；不预设供应商或协议 |
| `identity` | 已通过结构校验的 `FormalIdentity` 或 `null` |
| `expires_at` | 非负整数 Unix 秒或 `null`，拒绝布尔值和浮点数 |
| `csrf_token` | 服务端期望的非空字符串或 `null`，仅供纯比较，不进入身份 DTO、错误数据或日志 |

有效匿名上下文必须精确为 `mode=ANONYMOUS,state=ANONYMOUS,data_origin=UNKNOWN`，其余四个字段均为 `null`。匿名保留为 `null`，不补角色、权限、规划员或来源引用。

有效正式上下文必须为 `mode=FORMAL,data_origin=FORMAL_VERIFIED`，具有非空 `source_reference`、正式 `identity` 和有效 `expires_at`。正式上下文的 `state` 只接受 `ACTIVE / EXPIRED / DISABLED / REVOKED`。缺失来源、缺失到期事实及未知状态一律拒绝；不以默认时长补足。`csrf_token=null` 可用于读取，但不能通过写入校验。

`INTEGRATION`、`SYNTHETIC_INTEGRATION`、`UNKNOWN` 保留来源事实并拒绝正式访问。不得删除联调标记、复制联调会话或把来源重写成正式来源后调用本策略。上下文标记不能替代未来身份适配器对凭据、会话存储和来源隔离的验证。

### 3.3 服务端访问请求：`FormalAccessRequest`

| 字段 | 类型与规则 |
|---|---|
| `method` | 精确为 `GET / HEAD / POST / PUT / PATCH / DELETE`；其他值拒绝，不转换大小写 |
| `session_id` | 非空字符串或 `null`，对应请求会话关联标识 |
| `session_generation` | 非空字符串或 `null`，可由上层已有绑定上下文传入；不新增 HTTP 头 |
| `csrf_token` | 非空字符串或 `null`，对应提交的 CSRF 挑战值 |
| `required_permissions` | 无重复的权限字符串序列，可为空；由服务端路由或服务代码指定，不接受客户端自选授权条件 |

所有权限采用全量满足语义。权限白名单由总集成提供；本批不复制正式角色权限表、不扩展权限字典。空白名单只允许正式身份拥有空权限集，仍不授予任何默认能力。

## 4. 内部函数接口与纯策略

### 4.1 后端 Python

后端只依赖 Python 标准库，使用不可变数据对象；不导入 `app.main`、数据库、联调身份服务、Web 请求对象或共享资源底座。

| 函数/类型 | 精确输入 | 结果 |
|---|---|---|
| `validate_formal_identity(value, *, allowed_permissions)` | `value: object`；`allowed_permissions: frozenset[str]` | 返回 `FormalIdentity`；失败抛 `FormalIdentityPolicyError` |
| `resolve_formal_session(context, *, now, allowed_permissions)` | `context: FormalSessionContext`；`now: int` 为调用方注入的非负 Unix 秒；权限白名单同上 | 有效匿名返回 `None`；有效正式返回 `FormalIdentity`；其他情况抛错 |
| `require_formal_access(context, access, *, now, allowed_permissions)` | 上述上下文、`FormalAccessRequest` 及时间/白名单 | 通过后返回同一正式身份值；失败抛错，不生成授权状态 |
| `FormalIdentityPolicyError` | `message: str, code: int, status: int` | 只包含明确错误语义，不包含密码、Cookie、CSRF 或身份源原始凭据 |

服务端决策顺序：

1. 检查内部版本、字段类型及允许值；结构错误使用 `1001`。
2. 合法匿名由 `resolve_formal_session` 返回 `None`；受保护访问拒绝 `1101`。已标明联调或未知来源的上下文拒绝 `1101`，不得调用现有默认规划员回退逻辑。
3. 正式停用状态拒绝 `1103`；`EXPIRED`、`REVOKED` 或 `expires_at <= now` 拒绝 `1102`。`ACTIVE` 不能覆盖到期事实。
4. 校验正式 DTO 与权限白名单，检查上下文来源与 DTO 正式标记一致。
5. 对 `GET/HEAD`，提供了 `session_id` 时必须匹配；对四类写方法必须提供匹配的 `session_id`。任何方法若提供 `session_generation`，必须匹配当前代次；差异拒绝 `1106`。
6. 四类写方法必须有非空的期望值和提交值，使用 UTF-8 字节执行标准库常量时间比较检查 CSRF；缺失或不匹配拒绝 `1105`。非 ASCII 令牌与 ASCII 令牌执行同一规则；孤立代理项由结构校验拒绝，不泄漏编码异常。读方法不检查 CSRF。
7. 必需权限必须全部属于权限白名单并被当前身份持有；未知的必需权限或缺权拒绝 `1104`，不按角色名推导权限。

同一输入、同一显式时间和白名单应得到同一结果；函数不读取系统时钟、环境变量、文件、网络或数据库，不签发 Cookie、不轮换会话、不创建幂等回执。

### 4.2 前端 TypeScript

在独立校验模块内定义 DTO 类型，复用现有 `config/permissions.ts` 的只读权限白名单和 `services/types.ts` 的 `ApiError`；不改公共类型和 HTTP 客户端。

| 导出函数/类型 | 精确输入 | 结果 |
|---|---|---|
| `FormalIdentityDto` | 与第 3.1 节一致的独立只读类型 | 不替换共享 `AuthIdentity` |
| `decodeFormalSession(value: unknown)` | 未来可信同源身份接口返回的已拆包 `data` | `null` 原样返回 `null`；否则严格校验后返回独立 DTO；错误为 `INVALID_AUTH_RESPONSE` |
| `assertFormalSessionBinding(identity, expected)` | `identity: FormalIdentityDto \| null`；`expected: {sessionId: string; sessionGeneration: string}` | 成功返回 `void`；匿名抛 `AUTH_REQUIRED`，绑定或代次变化抛 `SESSION_REPLACED`，非法参数抛 `INVALID_AUTH_RESPONSE` |
| `assertFormalPermission(identity, requiredPermissions)` | `identity: FormalIdentityDto \| null`；`requiredPermissions: readonly Permission[]`，运行时仍校验 | 成功返回 `void`；匿名抛 `AUTH_REQUIRED`；未知或缺失权限抛 `FORBIDDEN`；非法结构抛 `INVALID_AUTH_RESPONSE` |

这三个函数只做显示和请求前置边界校验，不证明身份来源、不替代服务端授权、不调用 fetch、不访问 Cookie 或存储、不改变全局会话绑定。每次断言仍校验 DTO，避免用类型断言绕过运行时校验；不向调用方暴露可变的权限数组引用。

`integration_mode=true`、`data_origin=SYNTHETIC_INTEGRATION/UNKNOWN`、遗漏正式标记、未知契约版本及当前原样联调 DTO 均被拒绝。`decodeFormalSession(null)` 不产生默认规划员。

## 5. 错误码、权限、幂等与版本

| 业务码 | 后续 HTTP 映射 | 本批适用语义 | 既有前端语义 |
|---|---|---|---|
| `1001` | `422` | 内部请求/DTO 格式、字段或契约版本无效 | 本批前端本地结构拒绝使用既有 `INVALID_AUTH_RESPONSE` |
| `1101` | `401` | 匿名受保护访问；联调或未知来源不能作正式身份 | 既有数字映射为 `AUTH_CREDENTIALS`；本地匿名前置检查为 `AUTH_REQUIRED`，不改共享映射 |
| `1102` | `401` | 会话过期或已撤销 | `AUTH_EXPIRED` |
| `1103` | `403` | 身份已停用 | `AUTH_DISABLED` |
| `1104` | `403` | 无所需权限或未登记的权限要求 | `FORBIDDEN` |
| `1105` | `403` | 写操作 CSRF 缺失或不一致 | `CSRF_REJECTED` |
| `1106` | `409` | 会话关联或代次变化 | `SESSION_REPLACED` |

错误数字及客户端字符串含义来自现有 `auth-http.ts`、`integration_identity_service.py` 与接口文档，不新增业务错误码。正式适配层若将这些错误包装为 HTTP，仍使用 `{code,message,data:null}`；本批只抛纯策略错误，不实现路由或错误处理器。

权限：本批不授予任何权限，输入的权限快照及路由要求均需由可信服务端提供。匿名、联调来源或未知来源不能取得正式权限。

幂等：本批只有纯读取与纯校验，相同输入的重复调用没有持久化副作用；无 `request_id`、重放表、会话续期或写操作。登录、退出、刷新和切换的正式幂等语义均待身份协议确认。

版本：同时保留本批 `contract_version`、身份 `identity_revision` 与会话 `session_generation`，三者不互相替代，不与资源版本绑定。任何正式角色或身份代次变更需要上层重新取得身份并执行绑定保护；本批不实现变更操作。
