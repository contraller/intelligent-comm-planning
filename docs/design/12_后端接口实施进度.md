# 后端接口实施进度

> 最后更新：2026-10-20  
> 维护范围：`algorithm-service` 与 `front_design/radio-planning` 的 HTTP 联调契约  
> 详细字段定义以 [`03_接口文档.md`](03_接口文档.md) 为准，历史过程以 [`../../工作交接.md`](../../工作交接.md) 为准。

## 1. 状态口径

| 状态 | 判定标准 |
|---|---|
| 已完成（前端契约） | 后端路径、请求、响应、错误码和持久化满足当前前端严格校验，并通过后端测试及对应前端测试 |
| 已完成（算法接口） | 算法 HTTP 接口可执行并有后端测试，但尚未证明满足当前前端业务契约 |
| 部分完成 | 路径或算法已经存在，但版本、字段、持久化、权限或前端闭环仍有缺口 |
| 未开始 | 当前前端已有调用设计或项目已确定需要，但后端尚无对应实现 |
| 待确认 | 协议、验收口径或外部依赖尚未确定，不能按默认假设固化 |

仅注册 FastAPI 路由不代表“已完成（前端契约）”。没有完成请求校验、响应契约、持久化和联调验证的接口，必须标记为“部分完成”或“未开始”。

## 2. 当前主流程

| 顺序 | 用户操作 | 后端接口 | 当前状态 | 证据 |
|---:|---|---|---|---|
| 1 | 加载会话与规划资源 | `GET /api/v1/auth/session`、`GET /api/v1/auth/csrf`、`GET /api/v1/resource/*` | 已完成（前端契约） | 前端资源与规划 HTTP 测试通过 |
| 2 | 保存任务输入 | `PUT /api/v1/task-inputs/{task_id}` | 已完成（前端契约） | SQLAlchemy 版本持久化、幂等和版本冲突测试通过 |
| 3 | 运行 SR4 | `POST /api/v1/plan/sr4-flow` | 已完成（前端契约） | 提交绑定任务、输入、条件和资源版本 |
| 4 | 查询进度及结果 | `GET /api/v1/plan/tasks/{job_id}` | 已完成（前端契约） | 可从 `RUNNING` 轮询到 `SUCCESS`，未达标结果保留为 `3001` |
| 5 | 地图和表格展示结果 | 同上返回 `result` | 已完成（前端契约） | 节点、设备、链路、主备路由、频率、指标和检查项通过前端校验 |
| 6 | 保存方案版本 | `POST /api/v1/plans` | 已完成（前端契约） | 达标保存为 `SAVED`，未达标保存为 `REFERENCE` |
| 7 | 查询及打开方案 | `GET /api/v1/plans`、`GET /api/v1/plans/{plan_id}` | 已完成（前端契约） | 支持任务归属、分页、搜索和详情回读 |
| 8 | 确认为当前正式方案 | `POST /api/v1/plans/{plan_id}/confirm` | 已完成（前端契约） | 归属、版本、资源变化、幂等和唯一当前方案指针测试通过 |

当前已经形成以下可执行闭环：

```text
保存任务 → 提交 SR4 → 查询进度 → 展示结果 → 保存方案 → 查询列表 → 打开详情 → 确认正式方案
```

尚未形成以下闭环：

```text
多方案对比/导出 → 基于父方案调整并重新计算
```

## 6. 接下来完成顺序

1. **版本化多方案对比**：校验同任务 2–4 个方案，按请求顺序返回完整方案。
2. **版本化方案导出**：从数据库冻结快照生成 JSON/XLSX，不回读可能变化的算法运行文件。
3. **运行任务取消**：持久化取消请求及最终 `CANCELLED` 状态，处理完成态竞争。
4. **父方案调整与重新计算**：接入人工设备参数和主路径调整，保留父子版本关系。
5. **操作回执查询**：让前端在超时或断网后核实保存、提交、取消、保存方案和确认操作。
6. **任务列表、详情及服务端校验**：完成历史任务打开和导入校验闭环。
7. **正式鉴权与资源写接口**：在统一认证及双方分工确认后实施。

顺序调整时，必须在本文件记录原因，不得只在聊天记录中变更。

## 9. 维护规则

1. 开始接口工作前，先读取本文件确认当前接口、依赖和顺序。
2. 修改接口路径、字段、状态码、数据库结构或前端调用流程时，必须同步更新对应条目。
3. 接口完成后、提交代码前，必须更新状态、测试证据、真实联调结果、提交编号和下一接口。
4. 未执行的测试不得写成通过；只通过测试桩不得写成真实端到端完成。
5. 旧算法接口与新版前端契约必须分别标记，不得因路径相同合并计算进度。
6. 当前接口完成后，将“当前接口进度”替换为下一项，而不是删除历史证据；已完成内容写入对应清单和下方记录。
