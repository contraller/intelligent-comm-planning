## 0. 全局约定

任何一方（数据采集、算法后端、GIS 前端）产出或消费的数据，都必须满足本章约定。

### 0.1 规划区域

| 项 | 值 |
|---|---|
| 区域 | 太行山东麓（河北邢台西 — 山西左权），中心 `114.95, 37.30` |
| 规划 bbox | `114.2724, 36.7610, 115.6276, 37.8390` |
| 数据下载 bbox（外扩 20 km） | `114.0466, 36.5814, 115.8534, 38.0186` |

### 0.2 坐标与高程

| 项                     | 约定                          | 说明                                                       |
| --------------------- | --------------------------- | -------------------------------------------------------- |
| 地理坐标系                 | **WGS84 / EPSG:4326**       | 所有对外交换的经纬度一律用此坐标系，`lon` 在前 `lat` 在后（GeoJSON 惯例）          |
| 投影坐标系                 | **UTM / EPSG:32650**（50N 带） | 仅算法内部做距离、栅格计算时使用；不出现在接口里。若最终规划区域不在 50N 带，此项随区域调整         |
| 经纬度精度                 | 小数点后 **6** 位                | 约 0.1 m                                                  |
| 高程基准                  | **EGM96 大地水准面**，单位 **米**    | DEM 原始基准若不同，入库时统一转换                                      |
| 天线挂高 `antenna_height` | **相对地面**，单位米                | 与海拔 `elevation` 严格区分，绝对高度 = `elevation + antenna_height` |

### 0.3 单位

| 物理量   | 单位                    | 字段示例                              |
| ----- | --------------------- | --------------------------------- |
| 频率    | **kHz**               | `freq_khz`、`center_freq_khz`      |
| 带宽    | **kHz**               | `bandwidth_khz`                   |
| 发射功率  | **dBm**               | `tx_power_dbm`（短波 100 W = 50 dBm） |
| 天线增益  | **dBi**               | `antenna_gain_dbi`                |
| 接收灵敏度 | **dBm**               | `rx_sensitivity_dbm`（负值）          |
| 场强    | **dBμV/m**            | `field_strength_dbuvm`            |
| 信噪比   | **dB**                | `snr_db`                          |
| 距离    | **米**                 | `distance_m`；界面展示可换算 km           |
| 时延    | **毫秒**                | `delay_ms`                        |
| 速率/吞吐 | **kbps**              | `throughput_kbps`                 |
| 角度    | **度**，0–360，正北为 0 顺时针 | `azimuth_deg`；下倾角 `tilt_deg` 向下为正 |

> **约定理由**：功率统一用 dBm 而非 W，是因为链路预算、干扰叠加、灵敏度比较全在对数域进行，混用单位是这类系统最高发的缺陷来源。数据采集时若说明书写的是 W，在**入库脚本里**转换，不要让算法层做单位判断。

### 0.5 时间

一律 **ISO 8601 带时区**：`2026-09-08T14:30:00+08:00`。不接受 `2026/9/8 14:30` 这类格式。

### 0.6 全局枚举

以下枚举值**接口传英文码值**，中文仅用于界面展示。前端不得自行扩展。

```
device_class      HF                短波
                  VUHF              超短波

mobility          FIXED             固定站
                  VEHICLE           车载/移动站
                  MANPACK           便携站

node_role         TASK              任务节点
                  FIXED_STATION     已有固定站
                  RELAY             中继站
                  CANDIDATE         候选部署点

device_status     NORMAL            正常
                  FAULT             故障
                  OFFLINE           离线

link_state        EXCELLENT         优秀
                  GOOD              良好
                  WARNING           预警
                  FAULT             故障

fault_type        HW_FAILURE        设备硬件故障
                  LINK_DOWN         链路中断
                  SW_CONFIG         软件配置异常
                  EMI               电磁干扰

impact_level      SEVERE            严重
                  MODERATE          一般
                  MINOR             轻微

affect_state      INTERRUPTED       业务中断
                  DEGRADED          降级运行
                  NORMAL            未受影响

route_strategy    SHORTEST_PATH     最短路径
                  MIN_DELAY         最小时延
                  MAX_RELIABILITY   最高可靠性

countermeasure    FREQ_ADJUST       频率调整
                  CHANNEL_SWITCH    信道切换
                  POWER_OPT         功率优化
                  ROUTE_REBUILD     路由重构
```

> `link_state` 的四级取值直接对应 SR-6.2 要求的"优秀、良好、预警、故障"，不要另造第五级。
> `fault_type` 的四类直接对应甲方指定的四类典型故障（SR-5.1），**不可增删**，扩展只能走 `fault_subtype` 自由文本字段。

### 0.7 空值与缺省

- 缺失值统一为空字符串（CSV）/ `null`（JSON）。**禁止用 `0`、`-1`、`N/A`、`未知` 表示缺失**。
- 布尔值 CSV 中写 `true` / `false`，不写 `1` / `0` / `是` / `否`。
- 数组在 CSV 中用 **英文分号 `;`** 分隔，例如 `sub_bands = "3000-8000;8000-15000"`。

## 1. 基础地理与环境数据（师弟采集）

### 1.1 DEM 地形高程 `terrain_dem`

| 项      | 要求                                                                       |
| ------ | ------------------------------------------------------------------------ |
| 格式     | GeoTIFF (`.tif`)，单波段，Float32 或 Int16                                     |
| 分辨率    | **30 m**（1 弧秒）                                                           |
| 覆盖范围   | 完整覆盖规划区域，四周**外扩 20 km**（超短波绕射、短波地波计算需要边界外数据）                             |
| 坐标系    | EPSG:4326，若为投影需附 `.prj`                                                  |
| NoData | 明确标注，不得用 0                                                               |
| 推荐来源   | NASA SRTM 1 Arc-Second（OpenTopography）、ALOS AW3D30、ASTER GDEM v3、地理空间数据云 |
| 落盘位置   | `data/raw/terrain/dem_<区域名>.tif`                                         |

### 1.2 地物 / 土地覆盖 `landcover`

| 项    | 要求                                                           |
| ---- | ------------------------------------------------------------ |
| 格式   | GeoTIFF 栅格（优先）或 GeoJSON                                      |

| 类别   | 至少区分：水域 / 林地 / 草地 / 耕地 / 建成区 / 裸地 / 山地岩石                     |
| 必须附带 | **类别码 → 类别名 的对照表**（`landcover_legend.csv`，两列 `code,name_zh`） |

| 推荐来源 | ESA WorldCover 10m、GlobeLand30、中科院 CLCD                      |
| 落盘位置 | `data/raw/landcover/`                                        |

### 1.5 天线型号库 `antenna_model`

| 字段               | 类型     | 必填  | 说明                                                 |
| ---------------- | ------ | --- | -------------------------------------------------- |
| `antenna_id`     | string | 是   | `AM-0001`                                          |
| `antenna_name`   | string | 是   | 如 `鞭状天线 2.4m` / `双极天线` / `八木天线`                    |
| `device_class`   | enum   | 是   | `HF` / `VUHF`                                      |
| `gain_dbi`       | float  | 是   | 增益                                                 |
| `pattern_type`   | enum   | 是   | `OMNI` 全向 / `DIRECTIONAL` 定向 / `NVIS` 高仰角（短波近垂直入射） |
| `hbeamwidth_deg` | float  | 否   | 水平波束宽度，全向填 360                                     |
| `vbeamwidth_deg` | float  | 否   | 垂直波束宽度                                             |
| `height_range_m` | string | 否   | 可用挂高范围，如 `2-12`                                    |
| `polarization`   | enum   | 否   | `V` / `H` / `C`                                    |

> **NVIS 类型必须单列**：短波近距离通信靠高仰角天线打电离层反射，若把它按普通全向天线处理，50–300 km 段的覆盖会算错，而这正是 SR-4.2.3 要求呈现的"跳距与静区环带"的关键。

## 3. 故障域数据

### 3.1 故障类型字典 `fault_type_dict`

**固定四类，对应甲方指定场景（SR-5.1）**，不可增删。

| `fault_type` | 中文     | 适用对象  | 典型故障现象举例                       |
| ------------ | ------ | ----- | ------------------------------ |
| `HW_FAILURE` | 设备硬件故障 | 设备/节点 | 功放无输出、驻波比告警、电源模块失效、天线馈线断路      |
| `LINK_DOWN`  | 链路中断   | 链路    | 对端失联、误码率突增至不可用、握手超时            |
| `SW_CONFIG`  | 软件配置异常 | 设备/节点 | 频率配置错误、加密参数不匹配、协议版本不一致、跳频图案不同步 |
| `EMI`        | 电磁干扰   | 链路/区域 | 底噪抬升、SNR 骤降但发射正常、特定频点不可用       |

### 3.2 故障现象字典 `symptom_dict`

| 字段                | 类型     | 必填  | 说明                                                        |
| ----------------- | ------ | --- | --------------------------------------------------------- |
| `symptom_id`      | string | 是   | `SY-0001`                                                 |
| `symptom_name`    | string | 是   | 现象名称                                                      |
| `observable_from` | enum   | 是   | `DEVICE_STATUS` 设备自检 / `LINK_METRIC` 链路指标 / `MANUAL` 人工观察 |
| `metric_field`    | string | 否   | 若可由指标判定，写对应字段名如 `snr_db`                                  |
| `threshold_expr`  | string | 否   | 判定表达式如 `snr_db < 5`                                       |

> 现象字典单列，是为了让规则引擎、知识图谱、ML 三路推理**共用同一套现象编码**——SR-5.2 要求三路结果做加权融合，若各路的输入现象编码不一致，融合出的置信度没有意义。

### 3.3 故障案例 `fault_case`（待定 ）

| 字段                                                                     | 类型       | 必填  | 说明                         |
| ---------------------------------------------------------------------- | -------- | --- | -------------------------- |
| `case_id`                                                              | string   | 是   | `FC-0001`                  |
| `fault_type`                                                           | enum     | 是   | 四类之一，**这是 ML 的标签列**        |
| `fault_subtype`                                                        | string   | 否   | 更细的分类，自由文本                 |
| `object_type`                                                          | enum     | 是   | `DEVICE` / `LINK` / `NODE` |
| `device_class`                                                         | enum     | 否   | `HF` / `VUHF`              |
| `symptom_ids`                                                          | string[] | 是   | 现象编码，`;` 分隔                |
| `symptom_text`                                                         | string   | 否   | 原始现象描述                     |
| `snr_db` / `ber` / `packet_loss_rate` / `delay_ms` / `throughput_kbps` | float    | 否   | 故障时刻的链路指标快照，**ML 的特征列**    |

规模要求：**4 类故障，每类 50–100 条**。

### 3.4 故障规则 `fault_rule`（规则引擎，SR-5.2 b）

| 字段                      | 类型     | 必填  | 说明                    |
| ----------------------- | ------ | --- | --------------------- |
| `rule_id`               | string | 是   | `FR-0001`             |
| `rule_name`             | string | 是   |                       |
| `condition_expr`        | string | 是   | 判定条件，见下               |
| `conclusion_fault_type` | enum   | 是   | 结论故障类型                |
| `conclusion_component`  | string | 否   | 结论故障部件                |
| `conclusion_cause`      | string | 否   | 结论根因                  |
| `confidence`            | float  | 是   | **规则置信度 0–1**，融合计算的输入 |
| `priority`              | int    | 否   | 冲突时的优先级，数值大者优先        |
| `source_doc`            | string | 否   |                       |

`condition_expr` 语法（受限表达式，只支持以下算子，便于安全求值）：

```
支持：  and  or  not  ( )   >  >=  <  <=  ==  !=  in
变量：  数据字典中的字段名（snr_db、ber、device_selftest、symptom_ids…）
示例：  snr_db < 5 and ber > 1e-3 and device_selftest == "NORMAL"
        → EMI, confidence 0.85
示例：  "驻波比告警" in symptom_ids and tx_power_dbm > 0
        → HW_FAILURE / 天线馈线, confidence 0.9
```

规模要求：第一版 50–100 条。

### 3.5 故障知识图谱三元组 `kg_triple`（SR-6.3）

| 字段           | 类型     | 必填  | 说明                   |

### 3.6 故障场景 `fault_scenario`（SR-5.1 输入，前端传入）

| 字段              | 类型       | 必填  | 说明        |

`faults[]` 每项：

| 字段            | 类型       | 必填  | 说明                                 |
