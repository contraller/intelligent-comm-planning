## 页面闭环口径

每个现有页面的数据加载、筛选、分页、详情、写入、校验、版本冲突、幂等/超时核实、历史回读、导入导出与取消/离开保护均逐操作核对。数据操作由实际 HTTP 返回，不回退 Mock、不在浏览器计算业务结论；纯展开、选中、缩放等显示动作不机械新增业务接口。

现有构造数据支持的流程须真正持久化并形成页面闭环，不能止于独立工厂。缺真实协议/身份源/实测数据的动作保留明确待确认原因，不能假报真实下发、实时采集、正式登录或 ML 准确率；该外部边界须可在统一验收清单追踪。禁止物理清空历史；重置只可处理明确定义的当前草稿或生成保留历史的新版本。

全部页面包括资源管理、GIS/链路/覆盖/任务、规划及调整/比较/导出、干扰工作流、规划频点、设备配置/追溯/状态、频谱配置/观测、SR5/SR6 和系统管理。不得用占位方法总数代替接口数或验收结果。
