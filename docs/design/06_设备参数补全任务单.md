## 为什么这件事要紧

**天线增益和接收灵敏度是链路预算的必需项。** 系统计算「A 点发射，B 点能不能收到」的公式是：

```
接收功率 = 发射功率 + 发射天线增益 + 接收天线增益 - 路径损耗
余量     = 接收功率 - 噪声底 - 解调门限
```

天线增益缺失，这条公式就算不出来。目前 78 条天线里**只有 2 条有增益值，缺 76 条（97%）**，
因此整套系统还在用构造的假型号跑（生成脚本输出 `设备型号来源: CONSTRUCTED`），
覆盖范围、连通判定、部署规划全部建立在假参数上。

这批数据补齐后，放回 `data/raw/equipment_docs/`，重跑生成脚本会**自动切换到真实型号**，
无需改任何代码。

## 开工前：三条格式规范

采集来的表头已经和系统一致，**不要改表头、不要增删列、不要改列的顺序**。

### 1. 单位换算（手册上多为其他单位，必须换算）

| 手册写的 | 我们要的 | 换算 |
|---|---|---|
| 功率 W | `dBm` | `dBm = 10 × log10(W × 1000)`。1W=30，5W=37，10W=40，20W=43，25W=44，50W=47，100W=50，125W=51，150W=51.8，400W=56 |
| 频率 MHz | `kHz` | ×1000。1.6 MHz → `1600`，30 MHz → `30000`，512 MHz → `512000` |
| 灵敏度 μV | `dBm` | 按 50 Ω：`dBm = 20 × log10(μV) - 107`。0.35 μV → -116，0.5 μV → -113，1 μV → -107 |
| 灵敏度 dBμV | `dBm` | `dBm = dBμV - 107` |
| 带宽 kHz | `kHz` | 不变。窄带话音常见 3、6、12.5、25 |

### 2. 缺失值怎么填

- **手册里查得到** → 照抄换算后的值
- **手册里查不到** → **留空**，不要填 `0`、`N/A`、`未知`、`-`
- **不要编造数字。** 查不到就是查不到，缺口比假数据有价值得多 ——
  假数据会一路污染到覆盖计算和部署方案，而且事后极难追查

唯一的例外见下面「天线增益的兜底规则」。

### 3. 多值字段

用**英文分号**分隔，不要用逗号（会破坏 CSV）、不要用顿号。
例：`tx_power_levels_dbm = 30;37;43`、`bandwidth_khz = 3;6`

### B1 增益是重中之重

78 条里只有 2 条有增益。请按以下顺序处理每一条：

1. **手册里有明确增益值** → 照抄（单位 dBi；若手册给 dBd，`dBi = dBd + 2.15`）
2. **手册里没有** → 按下表取**类型典型值**，并在 `antenna_name` 后不做改动、
   但需在交付说明里列出哪些是估值

| 天线类型 | 频段 | 典型增益 dBi | 说明 |
|---|---|---|---|
| 短波鞭状（2–3 m） | HF | **-2** | 短于波长，效率低，增益为负是正常的 |
| 短波鞭状（车载 4 m 以上） | HF | **-1** | |
| 短波双极 / 倒 V（NVIS） | HF | **2** | 高仰角，用于近距离天波 |
| 短波宽带偶极 | HF | **2** | |
| 短波对数周期 / 定向 | HF | **8** | |
| 超短波鞭状（手持） | VUHF | **0** | |
| 超短波鞭状（车载） | VUHF | **2** | |
| 超短波全向增益天线 | VUHF | **6** | 常见基站全向 |
| 超短波八木 / 定向 | VUHF | **10** | |

> 取典型值**不是编造**：这些是天线类型的公认工程值，且我们会在数据里标明来源。
> 但**手册有值时必须以手册为准**，不要图省事一律套表。

### B2 其余字段

| 字段 | 现状 | 怎么填 |
|---|---|---|
| `pattern_type` | 缺 12 条 | `OMNI` 全向 / `DIRECTIONAL` 定向 / **`NVIS`** 短波高仰角（双极、倒 V、NVIS 专用天线都归此类） |
| `polarization` | 缺 76 条，且现有 2 条是英文长句 | 枚举：`V` 垂直 / `H` 水平 / `C` 圆极化。`Horizontal and vertical simultaneously` 这类填 `C` 或留空 |
| `hbeamwidth_deg` | 全缺 | 全向填 `360`；定向查手册，查不到留空 |
| `vbeamwidth_deg` | 全缺 | 查手册，查不到留空 |
| `height_range_m` | 全缺 | 可用挂高范围，如 `2-4`、`4-12`；查不到留空 |

**`NVIS` 这一类不能漏。** 短波近距离（50–300 km）靠高仰角天波反射，
按普通全向天线处理会把这一段覆盖算错，而这正是系统要出「跳距 + 静区」环带图的关键区段。
目前标了 NVIS 的只有 6 条，请对照手册确认是否有遗漏
（`DXE-NVIS-8040`、`AH-5NV`、各类 dipole / flagpole 大概率属于此类）。

1. 两个 CSV 用 **UTF-8 无 BOM** 保存（Excel 选「CSV UTF-8」，保存后用记事本打开确认开头没有乱码）

6. `source_doc` 全部非空
7. 没有 `0`、`N/A`、`未知` 这类占位值 —— 查不到就留空
