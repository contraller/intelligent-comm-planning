# 交付运行入口说明

## GIS查看任务与方案版本

在“GIS态势 → 任务查看”选择任务。“任务输入版本”对应已保存的任务配置；其下“已保存方案版本”按实际 `V1/V2/V3` 分列同名方案，标明状态和保存时间，超过10项可翻页。

选择一个版本后点击“查看方案完整网络”，查看该版本全部节点、主备链路和冻结地形，顶部显示方案版本及所属任务。点击“返回当前资源”可回到任务版本列表，继续选择其他版本。此操作只读，不重算、不改变当前正式方案。

“查看任务态势”仍显示任务输入中的参与节点和需求连线，用于核对输入；它不代表计算后的网络。若尚未保存规划方案，页面会明确提示，没有可打开的结果网络。
