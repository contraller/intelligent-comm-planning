# 交付运行入口说明

正式交付源码统一为 `codex/delivery` 分支，Windows 成品统一为 `RadioPlanning_Windows_x64_portable.zip`。包内前端、后端、算法和资源共同组成一个版本，具体提交及逐文件校验值见包根目录 `package-manifest.json`。

解压后双击“启动系统.cmd”，浏览器打开的地址即本次实例入口。默认地址为 `http://127.0.0.1:18480`；占用时自动选择后续空闲端口，以 `app/data/runtime/访问地址.txt` 为准。“停止系统.cmd”负责安全退出。

5324 与 8124 是开发验收实例的前端及后端，不是便携包需要额外启动的服务。开发实例和便携实例分别持有数据库，任务、方案、缓存及账号不会自动跨实例同步。统一代码不等于合并数据库。

更新已有实例前先安全停止，再备份完整的 `app/data/runtime`。替换程序时保留该目录，不重新初始化或重置账号；数据库迁移版本不一致时按报错单独安排升级，不能用空库替代。更新后重新启动并刷新浏览器，使前后端一同切换。运行实例不得在执行任务时直接覆盖后端文件。

源码仓库不携带开发数据库、个人日志、私有账号或密钥。便携包首次启动生成独立账号与数据库；使用构造联调资源和算法预测，不表示真实设备已执行或已取得现场观测。
