## 2. 干扰源根因和最终规则

### 2.1 根因及代码位置

原 `InterferenceSourceDrawer.vue` 将天线增益标为可空；资源校验及保存也接受空值。`interference_analysis_engine.py` 的分析校验却无条件读取增益，先抛出资源 ID 加英文字段名。原 `scripts/planning/interference.py` 还使用真假值默认和钳位，使挂高 0、占空比 0 与缺失混淆；OMNI 也会解析不适用方位角。

数据字典原允许存储空增益，但没有规定可用于传播计算的默认值。测试数据生成器为每条记录显式生成的 0–12 dBi 不是默认值；影响区域计算中的 0 dBi 参考接收机也不能作为发射干扰源的默认增益。因此没有将历史缺失增益擅自填为 0。

### 2.2 全字段口径

| 字段 | 新增/实际修改与分析规则 | 默认或来源 |
| --- | --- | --- |
| 名称、ID | 保留身份；聚合错误同时提供可读名称及字段定位 | 原始资源、场景版本 |
| 经度、纬度 | 有限数，分别为 [-180,180]、[-90,90]；运行还检查 DEM 范围 | 不补值 |
| 高程 | 可空；填写时为有限数 | 不补 0；当前传播模型的地面高程取自 DEM 剖面，资源高程仅保留展示 |
| 天线挂高 | 有限数且 ≥0 m；显式 0 保留 | 不补 10 m |
| 中心频率、带宽 | 有限数且 >0 kHz | 不钳位或补值 |
| 发射功率、天线增益 | 有限数；0 和负值合法；天线增益明确必填 | 无有据默认值，不补 0 dBi |
| 干扰类型 | 保留既有五类枚举校验 | 不扩大传播模型类型能力 |
| 方向图 | OMNI 或 DIRECTIONAL | 空时采用既有模型 OMNI，记录来源 |
| 方位角 | DIRECTIONAL 必填且为 [0,360)；OMNI 不参与计算 | OMNI 有效参数标为不适用，原始值仍保留 |
| 占空比 | 有限数且为 [0,1]；0 不贡献干扰功率 | 空时采用既有模型连续发射 1，记录来源 |
| 生效状态 | 明确布尔值；未生效源不贡献干扰 | 保留 false，不被默认 true 覆盖 |
| DEM 指纹、场景及资源版本 | 沿用原版本、范围和一致性保护 | 不使用合成地形兜底正式分析 |

历史未修改的空增益记录仍可读取，也不阻断无关资源的保存；分析前一次汇总所有缺失或无效参数，提示干扰源名称、中文字段和原因。新建或实际修改的源在保存前按相同规则校验。正式资源原值、标准化有效参数、运行冻结参数分别保留，不在分析过程中回写资源库。

运行详情新增 `analysis_parameters`，可查看实际参数与逐字段来源；该内容进入冻结哈希。旧运行没有该字段时明确为空，不能据此推定旧任务曾采用某个参数。

### 2.3 用户操作

1. 进入 GIS，点击“编辑资源”→“新建干扰源”。填写坐标、挂高、频率、带宽、功率、增益及其他必需项。
2. 增益必须按设备或场景填写；0 dBi 可以显式填写，高程可以留空。OMNI 不要求方位角；DIRECTIONAL 必须填写方位角。界面提示各字段范围及留空含义。
3. 点击“应用到 GIS 草稿”，再保存全部资源草稿。
4. 在有效规划网络的干扰分析中选择该源，保存场景版本，再提交分析；查看受扰节点、链路、结果和有效参数来源。
5. 对旧场景中的缺增益源，先补充资源参数，再保存新的场景版本。若修改资源导致原规划来源失效，须按已有版本流程使用有效来源；本次没有绕过来源校验。

参数错误使用 422/1001；来源、版本变化继续使用原冲突错误，不能把版本问题误报成缺参。

## 3. 转正、GIS 与导航的边界

- 确认请求新增严格布尔 `accept_quality_risk`，默认 false。完整的未达标方案只有明确接受风险后才能转正；缺失结果、来源变化、失权、快照或父版本不一致继续拒绝。
- 转正响应带可核验的 `quality_risk_confirmation`，审计与当前方案指针同事务。原结果、阈值、检查、缺口和质量状态不变；明确确认不等于指标达标，也不自动下发设备。
- GIS 撤去重复覆盖配置的实际挂载，未隐藏组件冒充移除。已有 `surface.coverage` 图层显示、地形、节点链路及设备状态/链路态势/频谱/干扰业务保留；共享覆盖组件、缓存、模型和规划页保持使用。
- `GET /api/v1/task-inputs/{task_id}/gis-snapshot?context=planning&revision=…` 读取现有不可变资源版本，无数据库迁移。严格核对任务、输入版本和快照身份，缺历史返回 404/2004，不把当前坐标拼入历史任务；缺失节点集中提示。
- 地图展示任务冻结节点及通联需求，通联需求线不冒充计算完成的路由。当前资源变化仅提示历史状态，不阻断查看。
- 频点普通查询、勾选和只读预检允许离页；实际未保存编辑仍需确认，保存中及提交结果未知仍需保护。离页取消只读请求，迟到响应不能覆盖新状态。
