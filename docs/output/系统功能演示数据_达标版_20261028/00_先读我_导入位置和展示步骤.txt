一、当前电脑已经导入完成，先直接展示，不必重新上传

入口：http://127.0.0.1:18480

1. 查看达标网络
   GIS态势 → 查看已保存方案 → 找到“演示01 已校验的规划网络” → 打开冻结网络。
   方案：PLAN-8654a33bfe7a48988da7242d4c8f6248，已确认、当前有效。
   任务：DEMO-20261028-QUALIFY-baseline。
   任务名称：演示达标试算 既有频池与数据通联。
   作业：tsk-f1004d868214。
   实跑：必要通联100%，全体通联98.29%，抗毁91.01%，频率冲突0，中继检查通过。
   独立逐边删除+BFS复核：89条必要通联原先全部连通，最坏单链路失效后保留81条，81/89=91.01%。
   覆盖未在本次SR4作业中计算，不把缺失值当作覆盖达标。

2. 查看规划输入与结果
   网络规划 → 打开任务 → 按上述任务编号查询并打开。
   本例：ND-0001→ND-0002，数据64 kbps，最大时延100 ms，最低可靠性0.95，最高可靠性路由，申请备用路由；balanced均衡预设。
   固定硬约束仍为必要通联100%、抗毁≥90%、中继≤2跳。
   使用原有可用频池；只在本任务排除前一包新增的36个DEMO频点，没有修改资源台账或降低频率/物理校验。
   这是另一组真实达标的演示参数，旧的两条HF需求参考结果仍为未达标，不是把旧结果改成达标。

3. 查看故障诊断
   故障诊断 → 左侧选择下面的构造场景，再选择相应诊断运行记录。
   “构造演示：短波设备功放故障”：候选根因“功放模块输出级晶体管击穿”。
   “构造演示：超短波链路中断”：候选根因“天线指向偏离”。
   “构造演示：超短波频率配置不一致”：候选根因“工作频率配置与对端不一致”。
   三例均已完成诊断和影响分析。可查看地理态势/网络拓扑、依据、根因、影响和建议，再预览/下载报告。
   三例均为需人工复核；规则缺自检输入时属于部分匹配，不代表已实际测出设备故障。

   将“实体类型”选为“故障”，选择案例实体E-01836，查看现象、原因、部件、处置及来源；选择节点后可“展开选中实体一跳”。

   旧的“演示02 故障知识录入与审核”草稿仍保留，未把它冒充本次诊断反馈。

二、只有需要再次导入时，才使用以下文件

文件：01_task_scenarios.csv ＋ 02_task_links.csv
入口：网络规划 → 第1步“任务与约束输入” → 导入。
方法：在文件选择框按住Ctrl同时选择这两个CSV → 解析并校验 → 查看差异 → 应用到草稿 → 保存任务。需要重新计算时再点击提交规划。
说明：两份必须一起选择；不要在这个入口上传故障CSV、方案导出表或报告。本包使用系统官方模板生成，已真实预检通过。

文件：05_故障场景_三类示例.csv
入口：故障诊断 → 导入场景。
方法：先选择“演示01 已校验的规划网络”（上面的PLAN编号）作为冻结网络来源 → 选择此CSV → 解析/预检 → 核对三例及对象 → 确认导入。
说明：导入保存场景，不自动等于诊断完成；需要新运行时，再提交诊断，诊断完成后提交影响分析。本机三例已经运行，不必为了展示重复导入。
