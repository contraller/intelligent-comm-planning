# 3.1 要求的状态和方式

## 3.1.1 状态和方式概述

本软件用于支撑短波/超短波智能规划系统的设备管理、网络规划、态势监控、故障诊断和系统维护等业务活动。根据[软件需求规格说明模板(1).docx](/e:/project2026-1/软件需求规格说明模板(1).docx)对“要求的状态和方式”的编写要求，以及项目资料对主要业务活动的描述，本软件在运行过程中存在多种用户可感知的软件工作状态。

本节所定义的“状态和方式”以用户可感知的软件工作模式为主，用于说明软件在不同业务活动下的使用边界、进入条件、允许执行的主要操作和切换关系，不扩展为复杂的软件内部状态机设计。

## 3.1.2 软件运行状态定义

### 3.1.2.1 初始/登录状态

- 状态名称：初始/登录状态
- 状态说明：软件启动后进入的初始状态，用于完成用户身份进入、访问入口展示和进入后续业务状态前的准备。
- 进入条件：软件启动，或用户退出登录后返回初始界面。
- 允许执行的主要操作：输入登录信息、执行登录、查看可进入的业务入口、退出系统。
- 退出或切换条件：登录成功后进入正常运行状态；登录失败时保持在本状态；用户主动退出时结束本次使用。

### 3.1.2.2 正常运行状态

- 状态名称：正常运行状态
- 状态说明：用户完成登录后进入的默认业务导航状态，用于选择后续业务功能并接收系统概览信息。
- 进入条件：用户登录成功，或从其他业务状态返回主业务界面。
- 允许执行的主要操作：查看系统概览、选择设备管理、选择网络规划、选择态势监控、选择故障诊断、选择系统维护、执行退出登录。
- 退出或切换条件：用户选择具体业务功能后切换到对应业务状态；用户退出登录后切换到初始/登录状态。

### 3.1.2.3 设备管理状态

- 状态名称：设备管理状态
- 状态说明：用于管理固定台站、车载台站及其所属短波/超短波设备的业务状态。
- 进入条件：用户在正常运行状态下选择设备管理相关功能。
- 允许执行的主要操作：查看设备信息、查看设备状态、执行设备面板操作、修改设备参数、查询设备配置结果。
- 退出或切换条件：用户返回主业务界面时切换到正常运行状态；用户选择进入网络规划、态势监控或故障诊断时切换到相应状态。

### 3.1.2.4 网络规划状态

- 状态名称：网络规划状态
- 状态说明：用于执行站点标绘、任务通联关系处理、组网方案生成和规划结果查看的业务状态。
- 进入条件：用户在正常运行状态下选择网络规划相关功能。
- 允许执行的主要操作：标绘固定站和车载站、导入任务通联关系、设置规划条件、查看规划结果、查看覆盖计算结果、查看干扰影响分析结果。
- 退出或切换条件：用户返回主业务界面时切换到正常运行状态；用户转入态势监控查看规划结果展示时切换到态势监控状态。

### 3.1.2.5 态势监控状态

- 状态名称：态势监控状态
- 状态说明：用于查看网络综合态势、设备监控态势、链路质量态势和频谱相关态势的业务状态。
- 进入条件：用户在正常运行状态下选择态势查看相关功能，或从其他业务状态进入态势查看页面。
- 允许执行的主要操作：查看网络拓扑、查看设备状态、查看链路质量、查看频谱态势、查看告警信息、按业务需要切换显示视图。
- 退出或切换条件：用户返回主业务界面时切换到正常运行状态；用户选择故障诊断时切换到故障诊断状态。

### 3.1.2.6 故障诊断状态

- 状态名称：故障诊断状态
- 状态说明：用于设置故障场景、查看故障推理过程、查看根因定位结果和查看修复建议的业务状态。
- 进入条件：用户在正常运行状态下选择故障诊断相关功能，或系统出现告警后用户进入故障诊断界面。
- 允许执行的主要操作：手动设置故障场景、查看故障现象、执行故障分析、查看根因定位结果、查看影响范围、生成诊断报告、查看修复建议。
- 退出或切换条件：用户返回主业务界面时切换到正常运行状态；用户切换到态势查看时进入态势监控状态。

### 3.1.2.7 系统维护状态

- 状态名称：系统维护状态
- 状态说明：用于执行系统配置、用户管理、角色权限管理、日志审计和基础维护操作的业务状态。
- 进入条件：具备相应权限的用户在正常运行状态下选择系统维护相关功能。
- 允许执行的主要操作：维护用户信息、维护角色权限、维护系统配置、查看系统日志、执行数据导入导出相关管理操作。
- 退出或切换条件：用户返回主业务界面时切换到正常运行状态；用户退出登录时切换到初始/登录状态。

### 3.1.2.8 降级运行状态

- 状态名称：降级运行状态
- 状态说明：当部分外部条件、设备接入能力或支撑数据不满足正常业务处理条件时，软件应在能力受限条件下继续提供已明确允许的部分功能。
- 进入条件：待确认。
- 允许执行的主要操作：待确认。
- 退出或切换条件：待确认。

说明：根据当前项目资料，降级运行状态的进入条件、功能边界和退出条件尚无明确规定，本状态保留为待确认状态，不在本阶段扩展为确定性验收要求。

## 3.1.3 状态切换关系

本软件主要状态切换关系如下：

1. 软件启动后进入初始/登录状态。
2. 用户登录成功后，软件应进入正常运行状态。
3. 用户在正常运行状态下选择设备管理功能后，软件应进入设备管理状态。
4. 用户在正常运行状态下选择网络规划功能后，软件应进入网络规划状态。
5. 用户在正常运行状态下选择态势查看功能后，软件应进入态势监控状态。
6. 用户在正常运行状态下选择故障诊断功能后，软件应进入故障诊断状态。
7. 系统出现告警且用户进入故障分析界面后，软件可从态势监控状态切换到故障诊断状态。
8. 具备相应权限的用户选择系统配置、权限管理或日志审计功能后，软件应进入系统维护状态。
9. 各业务状态在完成当前业务处理后，可返回正常运行状态。
10. 用户退出登录后，软件应返回初始/登录状态。
11. 降级运行状态的切换逻辑待确认。

## 3.1 资料差异与待确认事项

### 资料差异

- 当前资料对本软件是否需要明确定义降级运行状态存在信息不足。模板要求如存在多种状态则应定义，但项目原始资料未给出降级运行状态的明确业务边界。

### 待确认事项

- 降级运行状态的触发条件、允许执行的业务范围和退出条件待确认。
- 系统维护状态中“数据导入导出相关管理操作”的具体边界待在后续章节中结合接口和数据需求进一步确认。
