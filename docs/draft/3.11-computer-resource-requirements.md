# 3.11 计算机资源需求
## 3.11.1 计算机资源概述

本章规定短波/超短波智能规划系统软件在部署、运行、测试和验收过程中应满足的计算机资源需求。计算机资源需求用于支撑不少于 50 个短波节点、不少于 100 个超短波节点以及不小于 120 km × 120 km 地图范围内的资源管理、网络规划、态势呈现和故障诊断业务活动。
本章重点描述硬件资源、软件资源、通信资源、存储资源以及测试与仿真资源等方面的约束要求，不展开具体服务器型号、CPU 型号、端口号、数据库品牌版本或部署地点等未确认实现细节。对当前资料尚未明确的配置容量、并发规模和部署细节，统一标注为“待确认”或“待设计阶段细化”。

### 分项需求说明
#### SR-3.11-001 计算机资源覆盖范围要求

- 需求名称：计算机资源覆盖范围要求
- 需求内容：软件应明确支撑资源管理、设备孪生建模、知识图谱维护、网络规划、态势呈现、故障诊断、系统管理和审计追踪所需的计算机资源类别。
- 合格性方法：审查
- 追踪来源：《软件需求规格说明模板(1).docx》3.11 章节说明；docs/draft/3.2-csci-capability-requirements.md

#### SR-3.11-002 当前确认指标支撑要求

- 需求名称：当前确认指标支撑要求
- 需求内容：软件应在计算机资源配置上支撑不少于 50 个短波节点、不少于 100 个超短波节点和不小于 120 km × 120 km 地图范围的业务处理需求。
- 合格性方法：分析 / 审查
- 追踪来源：用户确认验收口径；docs/draft/3.2-csci-capability-requirements.md 3.2.9

## 3.11.2 计算机硬件资源需求

计算机硬件资源用于支撑系统核心业务处理、数据管理、地图加载、规划计算和态势显示。硬件资源需求应描述资源能力边界，而不直接限定未确认的具体硬件型号。

### 分项需求说明
#### SR-3.11-003 服务器硬件部署要求

- 需求名称：服务器硬件部署要求
- 需求内容：软件应支持部署在满足业务处理需求的服务器硬件环境中，并支撑资源管理、规划计算、态势刷新、数据存储和报告生成等处理活动。
- 合格性方法：分析 / 审查
- 追踪来源：《【非密】短波规划要求.docx》；docs/draft/3.2-csci-capability-requirements.md

#### SR-3.11-004 处理器资源适配要求

- 需求名称：处理器资源适配要求
- 需求内容：软件应支持在满足规划计算、态势处理和数据分析需求的处理器资源环境中运行；具体 CPU 架构和处理器配置待确认。
- 合格性方法：分析 / 审查
- 追踪来源：《半年落地问题清单.docx》；skills/risk-scope-control.md

#### SR-3.11-005 内存资源支撑要求

- 需求名称：内存资源支撑要求
- 需求内容：软件应支持在满足多模块并行业务处理、地图展示、数据缓存和态势刷新需求的内存资源环境中运行。
- 合格性方法：分析 / 审查
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.5、3.2.6、3.2.7

#### SR-3.11-006 网络接口资源要求

- 需求名称：网络接口资源要求
- 需求内容：软件应支持在满足设备接入、地图数据访问、文件导入导出、报告生成和客户端访问需求的网络接口资源环境中部署运行。
- 合格性方法：分析 / 审查
- 追踪来源：docs/draft/3.3-software-external-interface-requirements.md；docs/draft/3.4-software-internal-interface-requirements.md

## 3.11.3 计算机软件资源需求

计算机软件资源用于支撑操作系统、数据库、运行环境和客户端访问环境等软件层面的部署需求。本节描述运行环境需求，不将未确认的具体产品和版本直接写成硬性验收条款。

### 分项需求说明
#### SR-3.11-007 国产化软件环境适配要求

- 需求名称：国产化软件环境适配要求
- 需求内容：软件应支持在国产服务器、国产操作系统和国产数据库环境中部署运行。
- 合格性方法：演示 / 测试 / 审查
- 追踪来源：用户确认验收口径；docs/draft/3.2-csci-capability-requirements.md 3.2.9；《半年落地问题清单.docx》

#### SR-3.11-008 运行环境独立性要求

- 需求名称：运行环境独立性要求
- 需求内容：软件应对业务运行所需的操作系统、数据库、运行支撑环境和客户端访问环境提出明确要求，并在部署资料中给出对应约束说明。
- 合格性方法：审查
- 追踪来源：《软件需求规格说明模板(1).docx》；skills/requirement-quality-review.md

#### SR-3.11-009 客户端访问环境要求

- 需求名称：客户端访问环境要求
- 需求内容：软件应支持用户通过满足权限控制要求的客户端访问环境执行设备管理、网络规划、态势查看、故障诊断和系统管理等操作。
- 合格性方法：演示 / 审查
- 追踪来源：docs/draft/3.1-state-and-modes.md；docs/draft/3.3-software-external-interface-requirements.md 3.3.3

## 3.11.4 计算机通信资源需求

计算机通信资源用于支撑系统与外部设备、地图数据源、文件数据源以及客户端之间的数据交换，也用于支撑系统内部模块之间的业务调用和态势刷新。

### 分项需求说明
#### SR-3.11-010 局域网与网络通信支撑要求

- 需求名称：局域网与网络通信支撑要求
- 需求内容：软件应支持在满足局域网和网络通信条件的环境中运行，以支撑用户访问、设备接入、地图数据调用、态势刷新和报告导出等业务处理。
- 合格性方法：分析 / 审查
- 追踪来源：docs/draft/3.3-software-external-interface-requirements.md；docs/draft/3.2-csci-capability-requirements.md 3.2.6

#### SR-3.11-011 设备接入通信资源要求

- 需求名称：设备接入通信资源要求
- 需求内容：软件应为短波设备、超短波设备、光纤网络模块和频谱采集设备的数据接入预留通信资源能力；具体接入协议、字段和端口配置待确认。
- 合格性方法：分析 / 审查
- 追踪来源：docs/draft/3.3-software-external-interface-requirements.md 3.3.4、3.3.5、3.3.8

#### SR-3.11-012 态势刷新通信资源要求

- 需求名称：态势刷新通信资源要求
- 需求内容：软件应具备满足态势数据在不大于 1 分钟刷新周期内传输和展示的通信资源条件。
- 合格性方法：测试 / 分析
- 追踪来源：用户确认验收口径；docs/draft/3.2-csci-capability-requirements.md 3.2.9

## 3.11.5 存储资源需求

存储资源用于支撑设备数据、地图与地形数据、规划结果、知识图谱、故障诊断数据、日志审计数据和报告文件等业务数据的保存、调用和追溯。

### 分项需求说明
#### SR-3.11-013 业务数据存储覆盖要求

- 需求名称：业务数据存储覆盖要求
- 需求内容：软件应具备保存设备资源数据、设备配置数据、设备状态数据、站点部署数据、通联关系数据、链路质量数据、频率资源数据、地图与地形数据、覆盖计算结果数据、干扰分析数据、知识图谱数据、故障诊断数据、日志审计数据和报告文件数据的存储资源条件。
- 合格性方法：审查
- 追踪来源：docs/draft/3.5-csci-internal-data-requirements.md

#### SR-3.11-014 地图与地形数据存储要求

- 需求名称：地图与地形数据存储要求
- 需求内容：软件应具备支撑不小于 120 km × 120 km 地图范围显示和不少于 2 个地形地貌场景应用所需的地图与地形数据存储资源条件。
- 合格性方法：分析 / 审查
- 追踪来源：用户确认验收口径；《【非密】短波规划要求.docx》；docs/draft/3.2-csci-capability-requirements.md 3.2.9

#### SR-3.11-015 数据保存策略约束要求

- 需求名称：数据保存策略约束要求
- 需求内容：软件应支持按甲方数据管理要求配置数据保存策略；如资料未明确具体数据保留周期，应在设计阶段进一步确认。
- 合格性方法：审查
- 追踪来源：skills/srs-writing.md；skills/requirement-quality-review.md；docs/draft/3.5-csci-internal-data-requirements.md

#### SR-3.11-016 数据备份与恢复资源要求

- 需求名称：数据备份与恢复资源要求
- 需求内容：软件应具备支撑业务数据、配置数据、日志数据和报告文件备份与恢复处理所需的存储资源条件。
- 合格性方法：分析 / 审查
- 追踪来源：docs/draft/3.5-csci-internal-data-requirements.md 3.5.9；《软件需求规格说明模板(1).docx》

## 3.11.6 测试与仿真资源需求

测试与仿真资源用于支撑规划算法验证、覆盖分析验证、故障场景验证、接口联调和验收测试活动。

### 分项需求说明
#### SR-3.11-017 规划与覆盖测试资源要求

- 需求名称：规划与覆盖测试资源要求
- 需求内容：软件应具备用于验证网络规划、覆盖计算、干扰分析和预选配置处理的测试与仿真资源条件。
- 合格性方法：审查
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.5、3.2.9

#### SR-3.11-018 故障诊断测试资源要求

- 需求名称：故障诊断测试资源要求
- 需求内容：软件应具备用于验证不少于 3 个故障诊断场景的测试资源条件。
- 合格性方法：测试 / 审查
- 追踪来源：《【非密】短波规划要求.docx》；docs/draft/3.2-csci-capability-requirements.md 3.2.7、3.2.9

#### SR-3.11-019 接口联调测试资源要求

- 需求名称：接口联调测试资源要求
- 需求内容：软件应具备用于外部接口接入验证、内部接口联调验证和地图态势展示验证的测试资源条件。
- 合格性方法：审查
- 追踪来源：docs/draft/3.3-software-external-interface-requirements.md；docs/draft/3.4-software-internal-interface-requirements.md

## 3.11.7 计算机资源待确认事项

当前资料仍存在部分资源配置细节尚未确认，本节对相关事项进行汇总。

### 分项需求说明
#### SR-3.11-020 资源待确认事项标注要求

- 需求名称：资源待确认事项标注要求
- 需求内容：软件应对 CPU 架构、服务器型号、数据库选型、部署操作系统版本、DEM 数据体量、地图数据体量、并发用户规模、数据保存周期和外部接口带宽需求等未确认事项进行标注并在后续阶段细化。
- 合格性方法：审查
- 追踪来源：《半年落地问题清单.docx》；skills/risk-scope-control.md
