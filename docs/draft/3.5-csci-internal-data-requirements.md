# 3.5 CSCI内部数据需求

## 3.5.1 内部数据概述

本章规定短波/超短波智能规划系统软件在业务运行过程中需要管理和使用的内部数据需求。内部数据用于支撑设备管理、站点部署、通联规划、频率分配、覆盖计算、态势呈现、知识图谱维护、故障诊断、系统管理和审计追踪等业务活动。

本章所述内部数据需求重点描述数据类别、数据内容、数据来源、使用模块、保存要求和权限要求，不展开数据库表结构、字段命名、物理存储实现或中间件设计。对于当前资料未明确的数据保留周期、数据来源责任边界和数据规模细节，本章统一标注为“待确认”或“按甲方数据管理要求配置”。

### 分项需求说明

#### SR-3.5-001 内部数据分类要求

- 需求名称：内部数据分类要求
- 需求内容：软件应对支撑资源管理、网络规划、态势呈现、知识维护、故障诊断和系统管理的内部数据进行分类定义。
- 合格性方法：审查
- 追踪来源：《软件需求规格说明模板(1).docx》3.5 章节说明；docs/draft/3.2-csci-capability-requirements.md

#### SR-3.5-002 内部数据统一描述要求

- 需求名称：内部数据统一描述要求
- 需求内容：软件应对每类内部数据给出数据编号、数据名称、数据内容、数据来源、使用模块、保存要求、权限要求和待确认事项说明。
- 合格性方法：审查
- 追踪来源：skills/srs-writing.md；skills/requirement-quality-review.md

## 3.5.3 设备资源与配置数据需求

设备资源与配置数据用于支撑统一资源管理、设备孪生建模和规划参数选择。

### 分项需求说明

#### SR-3.5-004 设备资源数据维护要求

- 需求名称：设备资源数据维护要求
- 需求内容：软件应支持对设备资源数据进行录入、更新、查询和停用管理，以支撑不少于 50 个短波节点和不少于 100 个超短波节点的资源管理需求。
- 合格性方法：演示 / 测试 / 审查
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.2、3.2.9；用户确认验收口径

#### SR-3.5-005 设备配置数据保存要求

- 需求名称：设备配置数据保存要求
- 需求内容：软件应保存设备频率设置、天线参数设置和功率设置等配置数据，并支持后续查询和业务调用。
- 合格性方法：演示 / 测试
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.3；docs/draft/3.3-software-external-interface-requirements.md

#### SR-3.5-006 设备状态数据关联要求

- 需求名称：设备状态数据关联要求
- 需求内容：软件应使设备状态数据能够与对应设备资源数据建立关联，以支撑设备监控态势呈现和故障诊断处理。
- 合格性方法：演示 / 审查
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.3、3.2.6、3.2.7

## 3.5.4 站点、通联关系与链路数据需求

站点、通联关系与链路数据用于支撑站点部署规划、连接关系规划和链路态势展示。

### 分项需求说明

#### SR-3.5-007 站点部署数据管理要求

- 需求名称：站点部署数据管理要求
- 需求内容：软件应支持对固定站和车载站的站点部署数据进行保存和管理，并用于规划和态势展示处理。
- 合格性方法：演示 / 测试
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.5、3.2.6

#### SR-3.5-008 通联关系数据处理要求

- 需求名称：通联关系数据处理要求
- 需求内容：软件应支持对任务通联关系数据进行录入、导入、保存和调用，以支撑连接关系规划和资源分配处理。
- 合格性方法：演示 / 测试
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.5；docs/draft/3.3-software-external-interface-requirements.md

#### SR-3.5-009 链路质量数据展示支撑要求

- 需求名称：链路质量数据展示支撑要求
- 需求内容：软件应保存链路质量相关数据，并支持将其用于链路颜色和粗细变化展示。
- 合格性方法：演示 / 测试
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.6

## 3.5.5 频率、覆盖与干扰分析数据需求

频率、覆盖和干扰分析数据用于支撑规划结果生成、覆盖计算、干扰分析和结果展示。

### 分项需求说明

#### SR-3.5-010 频率资源数据管理要求

- 需求名称：频率资源数据管理要求
- 需求内容：软件应支持对频率资源数据进行保存和调用，以支撑频率资源分配、频谱态势展示和相关分析处理。
- 合格性方法：演示 / 测试
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.5、3.2.6

#### SR-3.5-011 地图与地形数据支撑要求

- 需求名称：地图与地形数据支撑要求
- 需求内容：软件应支持保存和调用地图与地形相关数据，以支撑不小于 120 km × 120 km 范围内的站点标绘、链路呈现和覆盖分析处理。
- 合格性方法：演示 / 测试 / 审查
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.5、3.2.9；用户确认验收口径

#### SR-3.5-012 覆盖结果数据保存要求

- 需求名称：覆盖结果数据保存要求
- 需求内容：软件应保存覆盖计算结果数据，并支持在规划结果查看、态势展示和报告输出处理中调用。
- 合格性方法：演示 / 测试
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.5；docs/draft/3.3-software-external-interface-requirements.md

#### SR-3.5-013 干扰分析数据保存要求

- 需求名称：干扰分析数据保存要求
- 需求内容：软件应保存干扰源信息、干扰影响分析结果和应对建议相关数据，并支持后续查询和报告输出。
- 合格性方法：演示 / 测试
- 追踪来源：docs/draft/3.2-csci-capability-requirements.md 3.2.5

## 3.5.10 内部数据待确认事项

当前资料下，以下内部数据事项仍待确认：

1. 设备状态数据的详细上报字段范围待确认。
2. GIS 地图数据和 DEM 数据的来源、授权和更新边界待确认。
3. 自动知识抽取依赖的数据来源和语料可用性待确认。
4. 故障诊断案例回写知识图谱的审核机制待确认。
5. 各类数据保留周期待确认，或按甲方数据管理要求配置。
6. 日志审计数据的保留策略待确认。

### 分项需求说明

#### SR-3.5-024 数据保留周期待确认要求

- 需求名称：数据保留周期待确认要求
- 需求内容：如原始资料未明确内部数据保留周期，软件应将相关要求表述为“数据保留周期待确认”或“按甲方数据管理要求配置”，不得自行编造月份、年份或天数。
- 合格性方法：审查
- 追踪来源：skills/srs-writing.md；skills/requirement-quality-review.md

#### SR-3.5-025 内部数据待确认标识要求

- 需求名称：内部数据待确认标识要求
- 需求内容：软件应对当前资料未明确的数据来源、数据保留周期、审核机制和字段范围保留“待确认”标识，不得写成确定性验收条件。
- 合格性方法：审查
- 追踪来源：AGENTS.md；skills/risk-scope-control.md；《半年落地问题清单.docx》
