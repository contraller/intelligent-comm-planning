# 3.3 CSCI软件外部接口需求

## 3.3.1 外部接口概述

本章规定本软件与外部对象之间的接口需求。本章所述“外部接口”包括用户通过图形界面访问本软件的接口，以及本软件与外部设备、外部数据源、外部文件和外部协作模块之间发生的数据交换接口。

根据[软件需求规格说明模板(1).docx](/e:/project2026-1/软件需求规格说明模板(1).docx)、[【非密】短波规划要求.docx](/e:/project2026-1/【非密】短波规划要求.docx)、[1111 2.docx](/e:/project2026-1/1111%202.docx)、[五大模块技术详细方案.docx](/e:/project2026-1/五大模块技术详细方案.docx)和[半年落地问题清单.docx](/e:/project2026-1/半年落地问题清单.docx)中的相关信息，本软件外部接口主要包括以下类别：

1. 用户操作接口
2. 短波/超短波设备接口
3. 光纤网络模块接口
4. GIS 地图数据接口
5. DEM 地形数据接口
6. 频谱采集设备接口
7. 文件导入导出接口
8. 报告导出接口

上述外部接口共同支撑 `3.2` 中定义的全域资源统一管理、设备孪生建模、知识图谱构建与查询、智能网络规划、综合态势呈现、故障智能诊断和系统管理等能力。对当前资料尚未明确的接口协议、数据格式、安全要求和协作边界，本章统一标注为“待确认”。

### 分项需求说明

#### SR-3.3-001 外部接口识别要求

- 需求名称：外部接口识别要求
- 需求内容：软件应识别并定义与外部用户、外部设备、外部数据源、外部文件和外部协作模块之间发生数据共享、交换或控制交互的外部接口。
- 合格性方法：审查
- 追踪来源：《软件需求规格说明模板(1).docx》3.3 章节说明；《1111 2.docx》

#### SR-3.3-002 外部接口分类要求

- 需求名称：外部接口分类要求
- 需求内容：软件应按用户操作、设备接入、协作模块接入、地图数据接入、地形数据接入、频谱数据接入、文件导入导出和报告导出等类别对外部接口进行分类说明。
- 合格性方法：审查
- 追踪来源：《软件需求规格说明模板(1).docx》3.3 章节说明；《【非密】短波规划要求.docx》；《1111 2.docx》

#### SR-3.3-003 待确认事项标识要求

- 需求名称：待确认事项标识要求
- 需求内容：软件应对当前资料未明确的接口协议、数据格式、责任边界和安全要求保留“待确认”标识，不得将其写成确定性接口条件。
- 合格性方法：审查
- 追踪来源：AGENTS.md；skills/risk-scope-control.md；《半年落地问题清单.docx》
