# Windows x64 便携包

本目录只负责打包和本地进程生命周期，不更改算法、接口、校验门槛或业务表。最终用户解压后双击“启动系统.cmd”，就绪后打开默认浏览器；“停止系统.cmd”仅通知本目录持有令牌的服务安全退出。

包内自带 Python 3.12.4 Windows x64 嵌入式运行环境、构建后的最新版前端、后端、地形、道路和构造资源。首次启动显式初始化独立 SQLite 和本地账号；已有库只核对迁移版本，不自动升级、重置或导入开发库。三类身份分离，初始口令按包实例随机生成，均需首次修改。`app/data/runtime/首次登录账号.txt` 只用于本地首次登录。运行数据沿用后端已允许的本树目录，不放宽路径校验；NTFS 限制凭据目录权限，exFAT 明示无访问控制的本地保管边界。

## 构建

在 Windows x64、Python 3.12 的构建环境中准备后端生产依赖和前端锁定依赖；不把构建机虚拟环境整体复制给用户。独立工作区可以用目录联接复用同一套前端 `node_modules`，不复制多份依赖。构建脚本运行类型检查及 Vite integration 构建，并按已安装分发元数据复制生产依赖及其许可。

从 Python 官方下载 `https://www.python.org/ftp/python/3.12.4/python-3.12.4-embed-amd64.zip`，固定 SHA256 为 `15fea3c9367653a85086fe37216b4d1a1c78688fa5e1587e1db0b0f658856564`。

```powershell
python packaging/windows/build_portable.py --python-embed F:/build/python-3.12.4-embed-amd64.zip --site-packages F:/build/venv/Lib/site-packages --node F:/build/node/node.exe --output F:/build/无线规划系统_Windows_x64
```

输出目录必须不存在。构建脚本同时生成 ZIP、SHA256 和包内逐文件清单；不会清理或覆盖已有包。ZIP 不含运行数据目录、开发数据库、个人日志、私有密钥、旧前端、Node.js 或 `node_modules`。不上传二进制大包到 Git 源码历史。

## 首次使用例程

成品ZIP根目录提供 `首次使用演示.html`，离线说明按初次登录、任务导入、真实规划、方案保存确认、故障导入及诊断、知识反馈审核发布的顺序操作。两份任务CSV必须同时选择；输入采用包内初始频池，不携带开发库额外频点排除编号。三例故障CSV须绑定本次已确认网络并核对对象，不引用开发电脑的PLAN、诊断运行或知识版本。

`build_portable.first_use_materials()` 是构建和复用旧运行环境的发布流程共用的资料清单与可移植性检查入口；缺少例程或公开手册时停止装配。`copy_first_use_materials()` 将资料复制到包内，所有文件进入逐文件校验清单。例程只包含公开构造输入与说明，不导入或复制开发数据库；第一次操作需要实际计算，不预造成功结果。

包内 `验收测试/` 同步提供最新验收记录的Word、PDF及证据索引。原43条用例的步骤与预期保留，实际结果按现有证据回填；记录区分实跑、定向验证、历史记录与未验证，正式验收勾选保持空白，不表示所有测试已通过。

## 验证范围

规划提交后，已有进度区按服务端阶段更新。返回任务输入页不会解除当前作业的提交保护；打开已保存任务时，会先核实已有作业状态。取消受理后需等待“已取消”，再修改并重新提交。单次 SR4 计算预算为 300 秒，预算耗尽会停止本次执行并说明“预算内未找到，尚未证明无解”；可由冻结条件反证的情况提前返回原因。有完整但未达标候选时保留参考结果和未达标结论。

用解压副本验证首次启动、地形/道路与 API、本地登录、独立数据库、重复启动、停止、重启持久化、中文带空格目录及占用端口；默认监听 `127.0.0.1`。自动化使用 `launcher.py start --no-browser`，最终桌面入口使用默认浏览器。

存在普通规划或诊断计算、提交请求时，停止入口拒绝中断并提示先等待或在页面取消；进入退出流程后拒绝新业务写入，核对工作流关闭结果后才报告安全停止。

它是 Windows 本地验收便携包，Linux/麒麟需按目标 CPU 架构另做运行环境包；不声称已完成其他系统实机兼容或真实设备协议验收。

本机验证已通过 17 项启停边界测试和 6 项独立解压副本 HTTP 检查，覆盖中文带空格目录、首次迁移/资源初始化、占用端口自动避让、三类账号首次改密、地形/道路静态资源、两类后台工作流、SR5/SR6 读取、重复启动，以及停止重启后的参数、账号和资源版本保留。整体搬迁后参数仍保留；桌面启动入口已实际调用默认浏览器，停止入口已实际停止服务。首次草稿暴露的运行目录不匹配和批处理错误码被暂停操作掩盖的问题已修复；没有为打包修改后端业务校验。
