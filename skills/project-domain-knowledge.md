# Project Domain Knowledge

## 项目对象

本项目面向短波/超短波通信网络的规划、态势展示、设备孪生建模和故障诊断。

## 核心业务对象

- 固定台站
- 车载台站
- 短波设备
- 超短波设备
- 通信链路
- 网络拓扑
- 频谱资源
- 干扰源
- 地形地貌场景
- 设备状态与性能参数
- 故障现象、故障原因、故障影响范围、处置建议

## 资料中稳定可采信的业务能力

以下能力同时得到原始技术要求和技术方案支持，可作为需求分解基础：

- 全域资源统一管理
- 基于 GIS 的态势呈现
- 固定站与车载站的部署与规划
- 通联关系与通信资源分配
- 不同地形地貌下的覆盖计算
- 干扰源标绘与影响分析
- 设备监控态势呈现
- 链路质量态势呈现
- 手动故障场景设置
- 故障推理、根因定位、影响范围分析
- 故障诊断报告与修复建议输出

## 当前确认验收口径

以下指标为当前确认后的验收口径，写正式需求时应优先采用：

- 短波节点数量不少于 50 个
- 超短波节点数量不少于 100 个
- 地图最大范围不少于 120 km x 120 km
- 地形地貌场景不少于 2 个
- 故障诊断场景不少于 3 个
- 仿真规划时间不大于 5 分钟
- 规划预选配置不少于 3 种
- 态势刷新时间不大于 1 分钟
- 支持国产服务器、国产操作系统、国产数据库环境部署

如《短波规划要求》或其他资料中出现短波不少于 10 个、超短波不少于 20 个、地图不小于 50km x 50km 等旧口径，当前均以已确认口径为准。

## 仅可作为背景或待确认的信息

以下内容主要来自技术方案或风险清单，不应默认写成验收要求：

- 150 台设备管理规模
- 30 秒采集周期
- 3 秒指令下发时延
- 3 至 5 跳图谱查询 200ms
- Neo4j、BERT、NSGA-II、ITM、P.533 等特定实现路线
- ARM 平台下图数据库性能推断
- 训练语料数量
- 具体外部接口格式与字段

## 五大模块关系约束

后续写作中，五大模块之间的关系应保持一致，不得前后漂移：

- 设备孪生建模提供设备数据。
- 知识图谱构建提供语义知识。
- 智能网络规划生成组网方案。
- 综合态势呈现展示设备、链路、拓扑、频谱、覆盖和告警。
- 故障智能诊断输出根因定位、影响范围和修复建议。

在章节写作时，如需要描述模块关系，应优先保持上述因果链条，不得把某一模块误写为另一模块的主要职责承担者。

## 术语提醒

- “知识图谱”是业务能力，不等于必须使用特定图数据库产品。
- “态势呈现”是能力要求，不等于必须使用某个前端框架。
- “规划”是输出组网方案和相关结果，不等于必须采用某一种算法。
- “故障智能诊断”在当前资料下应优先拆解为可验证的规则、推理、影响分析和报告输出能力。
